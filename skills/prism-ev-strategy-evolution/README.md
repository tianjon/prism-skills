# prism-ev-strategy-evolution

Prompt-first skill for analyzing one brand's EV strategy evolution from Obsidian vehicle notes.

The skill reads source notes through `obsidian-cli`, separates `纯电` and `增程`, includes discontinued models, and writes final analysis notes under `汽车/配置分析/三电分析/$品牌名/`.

For repository-wide minimum permission expectations, see `../../docs/permissions-matrix.md`.
