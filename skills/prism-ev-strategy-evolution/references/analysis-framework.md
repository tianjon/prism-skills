# Analysis Framework

This reference defines the reasoning frame for brand-wide three-electric analysis. Use it to keep the skill focused on strategic interpretation rather than parameter listing.

## 证据字段速查表

从 Obsidian 笔记中提取三电策略证据时，优先读以下字段：

| 分析维度 | 笔记分类 | 关键字段 |
|---|---|---|
| 电池化学体系 | 电池/充电 | `电池类型`（磷酸铁锂 / 三元锂） |
| 电池供应商 | 电池/充电 | `电芯品牌` |
| 电池技术标签 | 电池/充电 | `电池特色技术`（神行、麒麟、金砖等） |
| 电池容量 | 电池/充电 | `电池容量(kWh)` |
| 充电倍率 | 电池/充电 | 字段名即倍率值，如 `4.5` → `4.5C` |
| 峰值快充功率 | 电池/充电 | `最大快充功率(kw)` |
| 高压平台 | 基本信息 | 字段名 `800`，值 `800V` 表示已搭载 |
| 热泵 | 智能化配置 | `热泵管理系统`（标配 / 无） |
| 整备质量 | 车身 | `整备质量(kg)` |
| 纯电续航 | 基本信息 | `纯电续航里程(km)CLTC` |
| 综合续航（增程） | 基本信息 | `综合续航里程(km)CLTC` |
| 增程器功率 | 发动机 | `最大功率(kW)`（增程版专有） |
| 增程电池容量 | 电池/充电 | `电池容量(kWh)`（与发动机共存即为增程） |
| 上市时间 | 基本信息 | `上市时间` |

字段缺失时不要推测，在笔记中标记为「证据不足」。

## 品牌赢法框架

分析不能停留在"参数有没有进步"，还要回答品牌到底靠什么赢。默认把三电策略拆成 5 个问题：

1. `同价做强`
   品牌是否通过电池体系切换、平台复用、供应商重组、快充能力下放，把高规格三电能力做进主销价格带。
2. `体验做开`
   品牌是否通过更高电压平台、更强补能效率、更极端性能、更好的热管理，建立同价位难以复制的体验差异。
3. `场景做准`
   品牌是否把不同三电组合精准投向不同细分市场，例如入门纯电、主销高压纯电、大型 SUV 非纯电补能路线。
4. `上游做稳`
   品牌是否通过电芯供应商组合、电池特色技术、充电网络、自有平台、动力总成标准化来提高供给稳定性和主动权。
5. `竞争压力应对`
   品牌是否在回应替代路线压力、价格战压力、补能基础设施约束、供应链脆弱性，还是在主动定义新规则。

## 竞品对标方法

**孤立评价品牌三电能力没有商业价值。每条结论都必须有竞品基准。**

### 竞品识别规则

在开始分析前，先为被分析品牌的每个价格段确定主要竞品：

- 取被分析车型的上市价格 ±20% 范围内、相同车身形态、相近级别的 2-3 款竞品
- 优先选择同期上市或近期改款的竞品（时间差 ≤ 18 个月）
- 竞品数据来源：Obsidian 品牌库中的竞品笔记（如有）；缺失时使用公开参数并标注来源

### 对标维度矩阵

每个对标维度只比较有直接证据的数据，缺失字段标为「/」：

| 对标维度 | 被分析车型 | 竞品 A | 竞品 B | 差距方向 |
|---|---|---|---|---|
| 纯电续航 CLTC (km) | | | | 领先/持平/落后 |
| 充电倍率 (C) | | | | |
| 峰值快充功率 (kW) | | | | |
| 整备质量 (kg) | | | | |
| 续航效率 (km/kg) | | | | |
| 热泵覆盖 (是/否) | | | | |
| 增程纯电续航 CLTC (km) | | | | |
| 增程综合续航 CLTC (km) | | | | |
| 电池供应商层级 | | | | |
| 起售价 (万元) | | | | |

**差距方向判断标准：**

- 领先：比所有参照竞品强 ≥ 10%，或是明显差异化功能
- 持平：与最强竞品差距 < 10%
- 落后：被至少一款同价位竞品明显超越

### 竞争暴露分析

对标完成后，回答以下三个问题：

1. **当前最大暴露点**：哪个维度正在被竞品拉开差距，且用户感知最强？
2. **当前最强护城河**：哪个维度竞品短期内无法追平，且有上游或平台壁垒支撑？
3. **最近危险窗口**：哪款竞品即将发布改款或新平台，可能在哪个维度翻转差距？

## 价值链与供应商

供应商不是附属信息，而是品牌赢法的证据层。每个品牌都要额外检查：

- 不同电池容量、化学体系分别对应哪些供应商
- 同一车型的低配/高配是否采用不同供应商组合
- 年款切换时供应商是否变化，变化是否伴随成本、倍率、续航或价格的重构
- 是否出现"LFP 由 A 供应商承担、三元由 B 供应商承担"的清晰分工
- 是否出现超大电池、旗舰车型只绑定特定供应商
- 电池特色技术名称与供应商是否绑定，例如某品牌把技术名作为差异化叙事
- 供应商变化是为了降本、提速、提密度、保交付，还是为了品牌高端形象

### 化学体系策略

LFP vs NMC 的选择不只是技术权衡，更是价格带策略的直接体现：

| 选择 | 典型信号 | 策略含义 |
|---|---|---|
| 主销款用 LFP | 宁德神行、亿纬动力、衢州极电 | 以快充或低成本打同价竞争力 |
| 旗舰/长续航款用 NMC | 宁德麒麟、三元高密度 | 以能量密度守高端定价 |
| 同车型低/高配分用 LFP/NMC | 跨供应商组合 | 分层定价，用化学体系拉开配置梯度 |
| 全系 LFP | — | 成本优先，压低全线定价 |
| 增程版用 LFP | 电池容量小（30-55kWh） | 增程不追密度，优先成本和快充倍率 |

注意：供应商名称中若含母公司关联（如「时代吉利」= 宁德 × 吉利合资，「衢州极电」= 极氪系），需标记为垂直整合，这是「上游做稳」的一级证据。

这个维度要回答：

- 供应商变化有没有成为成本领先的来源
- 供应商变化有没有形成高端差异化壁垒
- 品牌对上游是否过度依赖单一供应商
- 供应商分层是否与价格带分层、车型角色分层一致
- 是否通过合资/自有供应商锁定关键技术或成本优势

## 品牌阶段

从品牌视角判断阶段，不只看时间顺序，还要看：

- 新车型导入节奏
- 纯电与增程的路线权重变化
- 高压平台、补能、热管理等技术节点
- 价格带扩张、上探、下沉或收缩
- 停售车型与替代车型之间的衔接关系

常见阶段标签：

- 导入期
- 放量扩张期
- 技术形象强化期
- 成本与效率优化期
- 产品线重整期

---

## 时间线

每个车型都要沿时间线梳理：

- 首发时间
- 关键改款
- 动力路线变化
- 价格带变化
- 配置上移或下放
- 停售节点

时间线分析要回答：

- 哪些变化是持续升级
- 哪些变化是一次性策略转向
- 哪些变化只是版本重分配

---

## 纯电路线

纯电分析重点：

- 电池容量与续航区间
- 电池供应商与特色技术如何分布
- LFP 与 NMC 分别承担哪些价格带和续航段
- 800V 或其他高压平台的引入和下放
- 快充速度（充电倍率 C）与峰值功率（kW）的双维度：倍率反映电池化学能力，峰值功率反映充电桩兼容性，需分开解读
- 热泵覆盖情况：纯电全系有热泵是底线，旗舰无热泵属于结构性缺陷
- 单电机/双电机的性能与效率取舍
- 纯电车型在品牌中的角色：旗舰、走量、守价位还是补技术形象

---

## 增程路线

增程分析重点：

- 电池容量与纯电续航（CLTC）
- 电池化学体系：增程版多用 LFP，若用 NMC 需解释原因
- 增程器功率定位：发动机最大功率（kW）与电机最大功率（kW）之比
  - 发动机功率 ≤ 电机功率的 60%：增程器定位为「补能兜底」，电机主导驾驶
  - 发动机功率 > 电机功率的 60%：增程器参与驱动，偏「油电协同」路线
- 油箱容积与综合续航的匹配：油箱越大综合续航越高，但也带来重量代价
- 馈电油耗与增程器热效率（笔记若无热效率字段，用 WLTC 馈电油耗替代）
- 热泵覆盖情况：增程版无热泵会直接损伤冬季纯电续航，是常见配置缺陷
- 增程车型在品牌中的角色：走量、过渡、下沉，还是替代纯电短板

---

## 纯电/增程同平台策略

当品牌在同一车型下同时销售纯电版和增程版，需要额外判断：

**定价关系**
- 增程版比同级纯电版贵：品牌将增程定位为高端补充，主打长途场景溢价
- 增程版比同级纯电版便宜：增程作为市场扩容手段，触达补能焦虑用户
- 两者同价：品牌用增程守住价格带，避免纯电降价压力

**技术一致性**
- 增程版是否沿用纯电版的 800V 平台和快充能力：是，则增程定位强；否，则增程是低成本补充路线
- 增程版的智驾传感器配置是否与纯电版对齐：差异大说明增程面向不同用户画像

**战略意图判断**
- 同价/降价 + 低技术一致性 → 增程是市场防御武器，应对增程竞品
- 加价 + 高技术一致性 → 增程是场景扩展，不是替代，两者并行
- 仅推出增程、停产纯电同级 → 路线切换，需在品牌阶段中标记

---

## 配置与价格

不能只看配置升级，要看升级是否映射到更高价格或主销带重构：

- 哪些三电能力成为高配专属
- 哪些能力被下放到主销版本
- 哪些供应商组合出现在主销款，哪些只出现在旗舰款
- 品牌是拿三电能力拉高成交价，还是提高同价位竞争力
- 配置变化更偏技术进步，还是商业重分配

---

## 配置与整车质量

要判断配置升级是否以整车质量增加为代价：

- 电池变大后整备质量是否同步上升
- 双电机和高压平台是否带来明显增重
- 增重是否稀释了续航、加速或补能收益

**量化计算方法**（可直接从笔记字段计算）：

| 指标 | 公式 | 含义 |
|---|---|---|
| 续航效率 | 纯电续航 CLTC(km) ÷ 整备质量(kg) | 每公斤车重换来多少续航，越高越好 |
| 快充强度 | 最大快充功率(kW) ÷ 指导价(万元) | 每万元买到多少快充能力 |
| 电耗密度 | 百公里耗电量(kWh/100km) × 整备质量(kg) | 越小说明轻量化做得更好 |
| 容量续航比 | 纯电续航 CLTC(km) ÷ 电池容量(kWh) | 能量管理效率，越高说明电耗控制越好 |

跨年款或跨车型比较时，优先计算续航效率和容量续航比。只有在数值差异明显时才下结论，字段缺失时不计算。

---

## 停售车型

停售车型不是噪音，而是品牌策略迁移的重要证据：

- 哪类车型先退出
- 被谁替代
- 是路线切换、价格带收缩，还是产品失败退出
- 停售后品牌的纯电/增程重心是否改变

---

## 维度关系

优先按下面的关系链组织结论：

1. 品牌阶段变化
2. 品牌赢法：同价做强 / 体验做开 / 场景做准
3. 纯电/增程路线权重变化（含同平台策略判断）
4. 车型组合与资源分配
5. 供应商与价值链结构变化（含化学体系分层）
6. 三电配置结构变化
7. 价格与配置关系
8. 配置与整车质量关系
9. 对品牌经营目标的反向解释

---

## 输出判断

每段结论用两个维度收敛：**品牌自身演进判断** + **竞品相对位置**。

### 品牌自身演进

- 明显技术进步
- 同价竞争力增强
- 体验差异扩大
- 上游掌控增强
- 结构性优化
- 配置重分配
- 商业化优先
- 价值效率下降
- 证据不足，暂不下结论

### 竞品相对位置

在每条演进判断后附加：`vs 竞品：领先 / 持平 / 落后`

示例写法：「充电能力：**明显技术进步**，vs 竞品：**领先**（同价位最强快充）」

**判断参考（基于实际数据模式）：**

- 阿维塔07切换至4.5C/420kW神行LFP → 明显技术进步，vs 竞品：领先（超越同价位小鹏G7的5C但更高峰值功率）
- 阿维塔12旗舰版无热泵 → 价值效率下降，vs 竞品：落后（理想L9/问界M9同价位均标配热泵）
- ZEEKR007分层供应（75kWh衢州极电LFP / 100kWh时代吉利NMC）→ 结构性优化，vs 竞品：持平（与主流分层策略一致）
- 小鹏P7+增程版定价低于纯电 → 商业化优先，vs 竞品：需判断增程纯电续航是否与理想L6持平

---

## 商业建议生成规则

分析完成后，每项**落后**或**价值效率下降**的结论必须对应一条可执行建议。

建议格式：
```
【暴露点】被哪款竞品在哪个维度超越
【影响范围】影响哪个价格段的用户决策
【建议动作】最小改动路径（OTA / 配置调整 / 平台升级）
【紧迫度】高（竞品已上市）/ 中（竞品改款中）/ 低（远期风险）
```

规则：
- 只针对三电相关维度提建议，不延伸到非三电配置
- 建议必须有竞品依据，不允许凭空提优化方向
- 紧迫度「高」的建议必须排在报告策略建议章节最前
