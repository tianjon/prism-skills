# Prompt Templates

Use these prompt blocks to keep execution consistent while still relying on agent reasoning.

## Discovery Prompt

先用 `obsidian search` 和 `obsidian read` 建立品牌证据地图，再开始写分析。

Suggested command pattern:

```bash
obsidian search query="汽车/品牌库/$品牌名" limit=200
obsidian read path="汽车/品牌库/$品牌名/<车型>/00-车型总览.md"
obsidian read path="汽车/品牌库/$品牌名/<车型>/当前款型/<款型>.md"
```

Discovery goals:

- 找全品牌下的全部车型，标记在售与停售
- 分离纯电与增程
- 找到价格、三电参数、整备质量、更新时间线相关证据
- 找到 `电芯品牌`、`电池特色技术`、`电池类型` 等价值链相关证据

**竞品发现（Discovery 阶段必做）：**

对每个价格段，从 Obsidian 品牌库中找 2-3 款主要竞品：

```bash
# 用价格段 + 级别关键词搜索竞品
obsidian search query="汽车/品牌库/<竞品品牌>/<竞品车型>" limit=50
obsidian read path="汽车/品牌库/<竞品品牌>/<竞品车型>/当前款型/<款型>.md"
```

竞品优先覆盖：同价位 ±20%、同车身形态、近 18 个月内上市或改款。

## 品牌总报告 Prompt

请基于 Obsidian 中 `汽车/品牌库/$品牌名` 下全部车型资料，以及已读取的竞品笔记，输出品牌级三电策略演进分析，保存到 `汽车/配置分析/三电分析/$品牌名/00-品牌三电策略总报告.md`。

写作要求：

- 明确划分品牌阶段，并说明证据
- 拆分纯电路线与增程路线
- 纳入停售车型的策略意义
- 分析价格带、配置结构与车型角色分工
- 解释品牌是在靠同价位竞争力、体验差异、场景聚焦，还是上游控制来赢
- 分析不同电池配置背后的供应商组合、供应商切换与其战略含义
- **每条策略结论必须包含竞品基准**，格式：「[判断]，vs 竞品：[领先/持平/落后]（[竞品名] [具体差距]）」
- 避免只罗列参数，重点解释品牌为什么在那个阶段这样配置三电能力

建议章节：

1. 结论摘要（含竞争位置总结）
2. 品牌阶段划分与判断依据
3. 品牌真正的赢法
4. 纯电路线演进
5. 增程路线演进
6. 纯电与增程的分工、替代与切换
7. 供应商与电池价值链变化
8. 各阶段车型组合与技术路线变化
9. 品牌三电能力的总体进步水平
10. 价格带、配置结构与车型角色分工
11. 停售车型对品牌策略迁移的意义
12. **竞品对标总结**（见下方格式）
13. **策略建议**（见下方格式）
14. 阶段性总结与关键拐点

**第12章 竞品对标总结格式：**

为每个主要价格段输出一张对标表：

| 维度 | $品牌名 | 竞品A | 竞品B | 差距方向 |
|---|---|---|---|---|
| 纯电续航(km) | | | | 领先/持平/落后 |
| 充电倍率(C) | | | | |
| 峰值快充功率(kW) | | | | |
| 热泵覆盖 | | | | |
| 增程纯电续航(km) | | | | |
| 增程综合续航(km) | | | | |
| 整备质量(kg) | | | | |
| 起售价(万元) | | | | |

**第13章 策略建议格式：**

按紧迫度排序，每条建议对应一个三电暴露点：

```
【暴露点】被哪款竞品在哪个维度超越
【影响范围】影响哪个价格段的用户决策
【建议动作】最小改动路径（OTA / 配置调整 / 平台升级）
【紧迫度】高 / 中 / 低
```

紧迫度「高」的建议排最前；无暴露点则写「当前三电策略无紧迫补课项，建议保持现有节奏」。

## 车型分报告 Prompt

请针对单一车型输出 `车型分报告`，并保存到 `汽车/配置分析/三电分析/$品牌名/车型分析/$车型名.md`。

写作要求：

- 按时间线梳理首发、改款、停售节点
- 识别纯电或增程路线定位
- 分析三电能力的真实进步与配置重分配
- 分析电池供应商、技术标签、容量方案之间的组合关系
- 解释配置与价格、配置与整车质量的关系
- **与直接竞品做头对头对标**，标出领先/持平/落后
- 说明这些变化是在强化成本优势、差异化，还是供应链控制
- 说明该车型在品牌阶段中的角色变化

建议章节：

1. 车型结论摘要（含竞争位置一句话）
2. 车型时间线
3. 动力路线定位
4. 三电维度演进
5. 同代配置梯度与价格关系
6. 配置与整车质量关系
7. 竞品头对头对标（2-3款直接竞品）
8. 该车型在品牌阶段中的角色变化
9. 总结：技术进步、价值效率与策略迁移

## 方法说明 Prompt

请先输出并写入 `汽车/配置分析/三电分析/$品牌名/01-分析方法与口径.md`，说明：

- 分析对象范围
- 纯电与增程拆分口径
- 时间线整理口径
- 品牌赢法分析口径
- 竞品选取标准与覆盖范围
- 供应商与价值链判断方式
- 配置与价格的判断方式
- 配置与整车质量的判断方式
- 字段缺失处理原则

## 车型清单与阶段映射 Prompt

请汇总品牌内全部车型，标记：

- 车型名
- 当前状态：在售 / 停售 / 待确认
- 动力路线：纯电 / 增程 / 待确认
- 所属品牌阶段
- 在品牌中的角色
- 主要直接竞品（1-2款）

将结果保存到 `汽车/配置分析/三电分析/$品牌名/车型清单与阶段映射.md`。
