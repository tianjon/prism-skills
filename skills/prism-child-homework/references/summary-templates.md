# Summary Templates

本文件是本技能写入 Obsidian 的各类 Markdown 模板。**所有模板严格遵守两层语言分离**：

- **frontmatter**：可以用内部技术字段（`根因图谱`、`层级`、`回访进度`、反思等级数字等）
- **正文（callout、段落、表格、标题）**：一律自然中文，**禁止出现** `根因 / 层级 / L1-L5 / 入队 / 出队 / 队列 / R1 / 元认知 / Schema / ZPD / 条目 ID` 等术语
- **允许** 在正文使用的中文常用词：`回访 / 掌握 / 学会 / 薄弱点 / 反思 / 回顾`（这些家长能秒懂）
- 完整清单见 `references/language-conversion.md`

占位符使用 `{{…}}` 风格。

## 通用排版规则

- **Callout** 标状态：`> [!success]` ✅ 正确、`> [!warning]` ◐ 部分正确、`> [!failure]` ❌ 错、`> [!tip]` 正确做法、`> [!note]` 口诀 / 小结、`> [!info]` 元信息、`> [!abstract]` 统计、`> [!question]` 题目、`> [!quote]` 孩子自答或家长备注。
- **折叠**：`> [!type]- 标题`（加 `-`）；展开用 `+`。答案必须折叠。
- **Highlight** `==…==` 用于核心答案、关键修改、关键单位。
- **Inline code** `` `value` `` 用于数字、单位、算式、路径、文件名。
- **Wikilink** 优先短名。同名冲突才退回 `[[路径/文件名|显示名]]`。表格里 `|` 转义为 `\|`。
- **Tag** 放在 frontmatter `tags:`，分层：`孩子作业/数学`、`批改/{{昵称}}`、`错题/{{昵称}}`、`练习/{{昵称}}`、`档案/{{昵称}}`、`知识点/{{知识点}}`、`单元/{{单元}}`、`根因/{{节点}}`、`层级/L{{N}}`。
- **Emoji** 仅在标题前作导航：🍎（孩子名）、📝 批改、📒 错题本、🧮 练习、🔁 回访、📊 统计、🎯 薄弱、🏅 已掌握、📅 历史、🔥 热力、📸 最近、🌱 概念、📐 难度、🪞 回顾、💡 建议。正文不撒 emoji。

## 数学符号选择规则

**⚠️ obsidian-cli 的坑**：`content="..."` 参数会把内容里的 `\t` 解析成制表符、`\n` 解析成换行。以 `\t` 或 `\n` 开头的 LaTeX 命令（`\times`、`\text{}`、`\to`、`\theta`、`\neq`、`\nabla`、`\tan` 等）会被破坏。

**对策（按优先级）**：

1. **优先 Unicode 数学字符 + inline code**：`×` `÷` `−` `²` `³` `→` `≈` `≤` `≥` `≠` `∞` `π` `√` `∠` `⊥` `∥` `△` `○`、分数 `1/2`、`½ ¼ ¾ ⅓ ⅔`。写成 `` `50 × 50 × 4 = 10000 cm³` `` 即可。
2. 需要 LaTeX 时避开 `\t` / `\n` 前缀：`\times → ×`、`\text{xx} → \mathrm{xx}`、`\to → →`。
3. 安全的 LaTeX：`\frac`、`\sqrt`、`\sum`、`\cdot`、`\mathrm`、`\rightarrow` 开头的都能用。
