# 数学建模专题课

本文件定义 `prism-child-homework` 里**数学建模专题课**的生成规范：模块化 callout 布局、分级配图、数学素养培养维度、难度矩阵、Markdown 模板。

每次批改后必须产出一份建模课文件，路径为：

```
批改记录/YYYY-MM/YYYY-MM-DD/数学建模/{UNIT_TOPIC}_{INDEX}.md
```

建模课**独立于批改诊断**：不复述错题，不参与回访队列。它以当日 `UNIT_TOPIC` 为切入点，把课堂知识推到奥赛靠齐的思维训练层次，并沿五个数学素养维度做纵向追踪。

---

## 1. 难度分级矩阵

| 阶段 | 年龄 / 年级 | 对标赛事 | 难度特征 | 允许的思维工具 |
|:---:|---|---|---|---|
| A | 6~8 岁 / 一二年级 | 趣味数学 / 数学幼苗组 | 具象情境，单步推理，数感拓展 | 画图、实物映射、数字规律、枚举 |
| B | 9~10 岁 / 三四年级 | 希望杯预备 / 走美杯初级 | 多步推理，逻辑链，开始出现"反设" | 列表穷举、奇偶性、简单不等式思想、容斥（集合图） |
| C | 10~11 岁 / 五年级 | 华杯初赛 / 走美杯高年级 | 构造、反证、模型迁移 | 抽屉原理、同余（初步）、倍数关系变形、方程组思想 |
| D | 11~12 岁 / 六年级 | 华杯决赛入门 / AMC 8 预备 | 分类讨论、最优化、计数原理 | 排列组合（初步）、不等式缩放、格点几何、简单概率 |
| E | 12~15 岁 / 初中 | AMC 8 / AMC 10 预备 / 华赛 | 完整建模链，多知识点综合，严格证明 | 代数恒等式、数论（整除、gcd）、图论直觉、递推关系 |

**阶段由 `年龄` 从 `pedagogy-by-stage.md` 派生，不得自行判断。**

## 2. 数学素养五维度（核心）

每节建模课必须沿下列**五个素养维度**设计内容——既作为练习题的隐藏 tag（进 frontmatter），也作为跨次追踪的刻度：

| 维度 | 中文简称 | 含义 | 典型训练动作 |
|:---:|---|---|---|
| M1 | 抽象 | 从具体情境剥离数量关系 | 找变量、去冗余条件、写"这题其实在问什么" |
| M2 | 推理 | 严密的逻辑链与证明直觉 | 分类讨论、反证、构造反例 |
| M3 | 想象 | 几何/空间/图形直观 | 画图、格点、对称、空间切割 |
| M4 | 归纳 | 从特例推一般规律 | 找规律、列表→猜想→验证 |
| M5 | 迁移 | 把模型用到新情境 | 认识到"这和 xxx 是同一个问题" |

### 每阶段的维度侧重（由年龄派生）

| 阶段 | 主攻 | 辅攻 | 暂缓 |
|:---:|:---:|:---:|:---:|
| A | M3 想象 · M1 抽象（初级） | M4 归纳（找规律题） | M2、M5 |
| B | M4 归纳 · M2 推理（初级） | M1 抽象、M3 想象 | M5 |
| C | M2 推理 · M5 迁移 | M1 抽象、M4 归纳 | — |
| D | M1 抽象 · M5 迁移 · M2 推理 | M3、M4 | — |
| E | 五维均衡 · M2/M5 加深 | — | — |

每节建模课必须**至少覆盖主攻维度**；练习题 3 题尽量不同维度（允许重叠 1 个）。

## 3. 建模三步法（讲解骨架）

讲解段一律用**三块 callout 套装**（呼应批改记录的模块化布局），每块 callout 内容可独立折叠、检索：

```markdown
> [!abstract] ① 抽象 —— 把情境翻译成数学
> {{找变量、常量；去掉无关细节；一句话"这题其实是在问……"}}
>
> ![[建模抽象_{主题关键词}.png|500]]

> [!tip] ② 建模 —— 写出数学式子或图
> {{核心式子 / 图 / 逻辑链；检查单位和边界条件}}
>
> ![[建模核心_{主题关键词}.png|500]]

> [!success] ③ 求解 + 验证
> {{按步骤求解；答案代回原题；如果某条件变了答案会怎么变？}}
>
> ![[建模求解_{主题关键词}.png|500]]
```

配图要求见 §6。若某张图生成失败，用占位 callout 替代（见 §6.3）。

## 4. 主题选取规则

建模主题从当日 `UNIT_TOPIC` 出发，按下列方式拔高：

| UNIT_TOPIC 示例 | 建模切入（C 阶段） | 主攻维度 |
|---|---|:---:|
| 长方体和正方体（体积） | 包装盒最优切割：用最少材料装最多货物 | M5 迁移 + M3 想象 |
| 分数运算 | 工程分配：多人合作、效率不同时怎么分阶段最快完成 | M1 抽象 + M2 推理 |
| 认识方程 | 鸡兔同笼变体：三类动物，用方程组建模 | M1 抽象 + M4 归纳 |
| 比和比例 | 地图比例尺：用相似三角形推断真实距离 | M3 想象 + M5 迁移 |
| 统计与概率 | 不公平抽签：用穷举验证是否公平，再用模型解释 | M4 归纳 + M2 推理 |

若当日 `UNIT_TOPIC` 找不到好的建模切入角度，选择**与孩子近期薄弱概念节点**相关的主题，在建模课开头说明"今天我们从另一个角度看 xxx 这个知识点"。

## 5. 练习题规范

每节建模课必须包含 **≥ 3 道练习题**，分层同时各压一个素养维度：

| 题号 | 定位 | 压的维度 | 要求 |
|:---:|---|:---:|---|
| 第 1 题 | 入门建模 | **主攻** | 三步法直接套，结果唯一，答案整数/简单分数 |
| 第 2 题 | 变式探索 | **主攻 + 一个辅攻** | 改变一个条件，要求判断"如果…会怎样" |
| 第 3 题 | 奥赛压轴 | **主攻 + 另一辅攻** | 对标阶段赛事难度，需要构造、分情况或巧妙观察 |
| 第 4 题（可选） | 开放题 | 任意 | 没有唯一答案，评分看推理完整性（阶段 D/E 推荐）|

**每题格式**（callout 套装）：

```markdown
### 第 N 题 · {{定位}} · 维度：{{M1/M2/…}}

{{题目正文，完整情境，不省略条件}}

> [!question]- 答案与思路
> **答案**：=={{结果}}==
>
> **① 抽象**：{{一句话}}
> **② 建模**：{{核心式子 / 图}}
> **③ 求解**：{{关键步骤，每步一行}}
>
> 💡 {{点睛：为什么要这样想}}
>
> 🧠 **训练的思维**：{{该题主要锻炼的素养维度中文名，不出现 M1~M5 记号}}
```

frontmatter tag：`维度/M{N}` 进 tags，供跨次统计用。

## 6. 配图规范（多张）

建模课每节最多 **5 张插图**，按位置分级：

| 图位 | 文件名 | 必要性 | 提示词要点 |
|:---:|---|:---:|---|
| 建模主图 | `建模主图_{主题关键词}.png` | 必画 | 一张概览图，呈现本次建模问题的整体场景 |
| 抽象图 | `建模抽象_{主题关键词}.png` | 必画 | 情境 → 数量关系的抽取过程（左原景、右骨架） |
| 核心建模图 | `建模核心_{主题关键词}.png` | 必画 | 核心式子、结构图、几何作图或表格 |
| 求解图 | `建模求解_{主题关键词}.png` | 按需 | 关键推导步骤 / 验证示意 |
| 奥赛压轴题图 | `建模奥赛_{主题关键词}.png` | 按需 | 第 3 题的关键结构（若口述难讲清） |

所有建模图存到：

```
图片/建模/{UNIT_TOPIC}_{主题关键词}_{图位}.png
```

生成方式与 `image-generation.md` 一致（调 `baoyu-imagine`，阶段适配风格同批改主图）。

### 6.1 提示词模板

```
小学{年级}数学建模示意图。主题：'{建模主题}' —— {图位说明}。

画面要素：{具体要素，中文标注，突出{主攻维度对应的视觉语言}}
风格：{阶段对应的视觉风格，见 image-generation.md §阶段适配}、中文清晰、不要水印。
```

### 6.2 阶段视觉语言

| 主攻维度 | 建议视觉元素 |
|---|---|
| M1 抽象 | 左右分栏（原场景 ↔ 抽象骨架）、箭头标注"抽象出……" |
| M2 推理 | 逻辑链 / 流程图 / 树形分支（分类讨论） |
| M3 想象 | 立体图、格点、对称轴、辅助线 |
| M4 归纳 | 表格（前 3 行给出）+ 问号行 + 规律箭头 |
| M5 迁移 | 双图并排："原题" ↔ "新情境"，中间连线"同一个模型" |

### 6.3 失败降级

某张图没生成 → 对应位置不嵌入 wikilink，替换为：

```markdown
> [!note] 本图生成失败
> 配图这次没跑通，不影响讲解。家长可以稍后手动再触发重生成。
```

## 8. 🔭 建模视角回顾问题库（按维度 + 阶段）

问题用自然中文，不出现 M1~M5 记号。下表按**每阶段主攻维度**先给，再给跨维度通用题。

### 阶段 A（6~8 岁 · 主攻 M3 想象）

1. 你能把题目里的东西在纸上画出来吗？画出来之后是不是更好理解了？
2. 如果把题目里的数字换一换，你还会做吗？
3. 你能用自己的话，把这道题讲给妈妈 / 爸爸听吗？

### 阶段 B（9~10 岁 · 主攻 M4 归纳）

1. 我们今天先试了小的情况再猜规律——这个办法你还在什么题里能用？
2. 这道题你有没有想到"反过来想"？反着想的结果是什么？
3. 如果题目里有三种情况，你怎么确保一种都没漏？

### 阶段 C（10~11 岁 · 主攻 M2 推理 & M5 迁移）

1. 今天用到了 {{概念名}}，你能用自己的话说清楚它是什么意思吗？
2. 这道题的"最坏情况"是什么？我们为什么要先考虑最坏情况？
3. 你有没有发现今天的建模和以前做过的哪道题"长得很像"？像在哪？

### 阶段 D（11~12 岁 · 主攻 M1 抽象 & M5 迁移）

1. 今天分了几种情况？每种情况结束时你怎么验证没有漏？
2. 这道题的答案如果变一个条件会怎么变？你能给出一个"更难的变体"吗？
3. 如果把题目里的"{{具体情境}}"换成完全不同的场景，模型还能用吗？

### 阶段 E（12~15 岁 · 五维均衡，M2/M5 加深）

1. 我们今天建立的模型有什么局限？什么情境下会失效？
2. 这道题的解法能不能推广？试描述一个更一般的命题。
3. 如果用另一个数学分支（图论 / 概率 / 数论）来看同一个问题，你会怎么建模？

## 9. 内容禁止词

同批改记录禁用词表（见 `references/language-conversion.md`），额外禁止在正文中出现：

- "奥赛题目" → "今天的挑战题"
- "超纲" → "课本还没学到，但我们可以理解它"
- "你做不到"（Growth Mindset 绝对禁止）
- "M1 / M2 / M3 / M4 / M5" 这种代号（代号只进 frontmatter 和 §思维成长追踪 给家长看的 callout）

**允许**出现的专有数学名词（不需要回避，但必须先解释）：

抽屉原理、容斥原理、奇偶性、同余、穷举、构造法、反证法、递推、不等式、排列、组合、最坏情况、相似三角形、几何变换

## 10. 与批改记录的连接规则

建模课**不重复讲解**批改记录里已有的错题内容。它只取 `UNIT_TOPIC` 作为切入主题，内容完全独立。

连接方式：

- 建模课末尾 🔗 关联区 wikilink 到同日简洁 + 完整批改记录，以及**上一次建模课**（用于孩子回看自己的思维轨迹）
- 完整批改记录末尾 🔗 关联区加一行链到建模课
- 简洁批改记录末尾**不强制链**到建模课（简洁模式设计为轻量）；对话回应里提醒家长"今天还有一节建模课"
