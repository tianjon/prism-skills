# Error Taxonomy

本文件是**技能内部**的错题诊断框架。术语（层级 L1~L5、根因节点）**只用于 frontmatter 和 tags**，不允许出现在用户可见的正文里。

- 用户可见的错误分类（四类："题意没看清 / 想错 / 算错 / 写错"）见 `grading-rubric.md` 的"用户可见的问题分类"一节
- 用户可见语言的禁用词清单与翻译规则见 `language-conversion.md`

本文件是错题诊断的统一口径。把"错在哪"拆成**两条互相正交的轴**，同时给每道错题打两个内部标签。这样长期积累的错题才能做因果分析，不只是流水账。

## 为什么要双轴

传统的"计算错/概念错/粗心"五标签太粗：一道"单位错"既可以是因为赶时间漏写（编码层 · 粗心），也可以是因为根本没理解体积需要立方单位（理解层 · 概念）。两者对应的干预完全不同。

- 第一轴（**层级轴**）回答："**错在哪一层**？"——从读题到写答，五个阶段层层递进（Newman's hierarchy，1977，被多国小学数学教研沿用）。
- 第二轴（**根因轴**）回答："**错在哪个概念节点**？"——错题的底层都能归到某个概念图节点（如"维度感知"、"守恒"、"负数意识"）。同一根因跨题反复出现，就是真正的薄弱处。

## 层级轴 · Newman's Hierarchy

按解题过程的顺序，错误可能发生在五个阶段。必须从早到晚判断：**若读题就错了，后面层级不必再诊断**。

| 层级 | 含义 | 典型表现 | 干预重点 |
| :---: | --- | --- | --- |
| **L1 读题** | 字词识别、数字/符号看错、题干看漏 | 把"7"抄成"1"、漏了"不计"、把"多"读成"少" | 放慢读题、勾画关键量 |
| **L2 理解** | 题意理解偏差；情境—数学结构未建立 | 排水法题不知道"放入石头 → 水面上升" | 用图示/实物重建题情境 |
| **L3 转换** | 知道题意，但选错了方法/公式/策略 | 该用 V=Sh 却用 V=abc | 构建"题型 ↔ 方法"的 schema |
| **L4 策略/执行** | 方法对，步骤推进出错 | 分数通分公倍数求错；多位数乘法进位错 | 精确化执行、worked example |
| **L5 编码** | 思路和结果对，但写答的呈现错 | 单位写错、漏写答、抄错最终结果 | 答前自查清单、规范意识 |

**规则**：
- 一道错题**优先标注最早出现错误的层级**。
- 若中间层对、末层错（如策略对但编码错），只标末层。
- 若同一题多层错，主标签取最深层（不含回退到更早层），副标签列出后续层。

### 如何使用层级信息

| 层级 | 本技能的动作 |
|---|---|
| L1-L2 密集 | 讲解时必须回到题情境。用图示/具象重建。家长侧给"复述题目"练习。 |
| L3 密集 | 在错题本里显性写出"此题属于哪类题 → 用哪个方法"，构建题型 schema 索引。 |
| L4 密集 | 提供 worked examples、分步骤练习，暂时降低题量、提高示范密度。 |
| L5 密集 | 元认知"答前三问"成为本周必训。 |
| 跨题一致 | 在总结中显式指出"近 N 次批改集中在 L? 层"，方向性建议家长侧。 |

## 根因轴 · 概念节点图

数学知识不是扁平清单，而是**层级网络**。很多表面不同的错，其实根在同一个概念节点。例：

- "cm² vs cm³ 写错"（L5 编码）
- "长宽高扩大 2 倍，表面积扩大几倍"（L3 转换）
- "为什么不能求体积"（L2 理解）

三者看似不同，但根都在 **"维度感知（dimensional sense）"**——孩子对"几维"和"单位次方"、"倍数规律指数"的同构关系还没建立。这就是**根因节点**。

### 常见根因节点清单（按课标范围）

低年级：
- `数感` — 10 以内、20 以内加减的直观理解
- `数位` — 十位/个位/百位的位置值
- `守恒` — 数量守恒（Piaget 经典）
- `加减互逆`
- `乘法作为重复加` — 对乘法的底层理解

中年级：
- `分数作为整体的一部分`
- `小数作为分数的另一种写法`
- `面积作为平面覆盖`
- `乘法结合/分配律的直观理解`
- `数量关系表达`（多/少/倍/比）

高年级：
- `维度感知` — 长度/面积/体积与单位次方的对应
- `比例推理` — 包括 n², n³ 和反比例
- `守恒升级版` — 面积/体积在变形中的守恒
- `方程作为未知量求解工具`
- `分数与小数与百分数互换`
- `平均的意义` — 不只是算法

初中：
- `代数符号抽象` — 字母代表量
- `负数的意义`
- `函数作为输入—输出机器`
- `证明的结构`（条件、结论、依据）
- `几何变换`（平移/旋转/对称）

### 根因图谱的记录

在 `孩子档案.md` 的 frontmatter 维护一个 `根因图谱` 计数字段：

```yaml
根因图谱:
  维度感知: 3        # 近 30 天出现 3 次
  分数通分: 1
```

- 每次批改在错题打标时顺便累加对应根因计数。
- 月报 / 年报时重新评估：连续 3 次批改未出现的节点 → 计数归零；反复出现 ≥ 3 次 → 升级为"主薄弱"；同一根因相关错题在间隔回访中连续 3 次通过 → 标记"稳固"并从计数中移除。

## 两轴组合示例

示例（一个五年级孩子某次批改的三道错）：

| 错题 | 层级 | 根因节点 | 组合解读 |
|---|:---:|---|---|
| 题 8 `540 cm²` 应为 `cm³` | L5 编码 | 维度感知 | 写答时把"三维体积"编码成二维单位——表面是"粗心"，底层是"维度—单位对应"未自动化 |
| 练 2 "表扩大 3~4 倍" 应为 4 倍 | L3 转换 | 维度感知（比例推理） | 不是算错，是没选对规律——面积—平方的映射未建立 |
| 题 6(1) "不知原头高度" 应为"不知底面积" | L2 理解 | 维度感知（概念表达） | 公式里"底面积"这一维概念在脑中缺位 |

**共同根因**：三道都在 `维度感知` 节点。表层是三种不同错，深层是同一块肌肉没长好。**这就是分层诊断的价值**——单看"单位错/概念错"会以为是三件事，看根因图谱立刻看到是一件事。

对应的教学干预：**不是做 10 道单位辨析题**（只治 L5），而是从根因节点开始——用方块搭 2×2×2 具象化"三维 = n³"，再逐层回到 L3 变化规律、L5 单位书写。

## 使用规则

1. 每道错题在批改记录中**必须同时打两个标签**：`层级: L?`、`根因: <节点名>`。
2. 同一根因节点在**同一批改内**被触发多次，总结为"本次主根因"。
3. 跨批改的根因累积进 `根因图谱`，驱动月报/年报的"主薄弱"判定。
4. 根因节点命名必须使用上面清单中的词条；新增节点需要在本文件补充定义，避免生造。
5. 如果一道题实在找不到清单内的根因，标 `待归类`，等总结阶段由人类或高 context 模型归并。

## 根因图谱衰减算法

在 `孩子档案.md` frontmatter 的 `根因图谱` 里累积概念节点命中次数。为避免"旧错永远压住新错"的优先级污染，按下面规则衰减：

- 每次批改**写回档案前**，对 `根因图谱` 中每个节点计算**距上次命中的批改数**（查近期批改记录的 `根因图谱命中` 字段）
- 连续 **≥ 3 次批改未再命中** → 计数 **−1**（最低不低于 0）
- 计数降到 0 → 从 `根因图谱` 删除该节点；若该节点下有错题稳固过，加到 `已掌握知识点`
- 每次批改的新命中 → 计数 **+1**（或初始为 1）

这样旧节点会在孩子长时间不再出同类错时自然淡出，新出现的节点能及时浮现。

## 错题 ID 规则（避免冲突）

错题 ID 格式 `YYYY-MM-DD-<suffix>`：
- 单日第 1~26 道错 → `a`、`b`、…、`z`
- 第 27 道及以后 → 两字母 `aa`、`ab`、…、`az`、`ba`、…
- **同日不同批次不重置**：第 2 次批改的第 1 个错题接上一次的序号

实际作业里极少单批 > 26 错；规则主要为极端情况兜底。
