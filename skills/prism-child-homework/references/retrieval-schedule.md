# Retrieval Schedule

本文件定义**间隔回访**机制——技能内部用的。术语（`R1~R5`、`到期`、`入队 / 出队`、`重置`）**只用于 frontmatter、队列表格、技能内部决策**，**不允许出现在批改记录正文、错题本正文、总结正文**。

**允许**在正文用的自然词：`回访 / 回访题 / 掌握 / 学会 / 薄弱`。详情见 `language-conversion.md`。

让错题本从"存档"变成"循环训练器"。核心依据：Ebbinghaus 遗忘曲线、Bjork 的"desirable difficulty"、Karpicke & Roediger 的"testing effect"——学习科学里成熟的原则。

## 核心主张

- 错题当天改对不代表学会。记忆稳定化需要**多次间隔提取**。
- 最有效的提取时机**不是刚刚复习后**，而是"快忘了但还没完全忘"时。这就是"desirable difficulty"。
- 被动重读错题本**几乎无效**；真正有效的是让孩子**再做一遍**。

## 间隔序列

每条错题按下列时间点做一次"回访"（把同一知识点的变式题重新插入下一次练习）：

| 回访次（内部代号） | 距离上次通过的天数 | 目的 |
| :---: | :---: | --- |
| R1 | `+1 天` | 抓住遗忘曲线最陡处 |
| R2 | `+3 天` | 第一次稳固 |
| R3 | `+7 天` | 一周记忆桩 |
| R4 | `+30 天` | 月度巩固 |
| R5 | `+90 天` | 季度级迁移检验 |

## 通过 / 重置 / 掌握

**通过标准**：
- 当次批改中**同类变式题做对** → 这条错题的本次回访进入下一间隔（R1 → R2 → ...）
- 当次批改同类题**仍错** → 回访重置为 R1，重新开始；同时根因节点命中计数 +1

**掌握标准**：
- 连续**任意 3 次回访通过**（不限间隔） → 条目标记"已掌握（mastered）"，从活跃队列移除
- 但根因图谱保留记录供长期分析

## 概念节点"整体掌握"的判定

> **问题**：什么时候把一个概念节点（比如"维度感知"）标记为"整体掌握"并生成专题总结？

规则：**同时满足**两个条件

1. **该节点下所有活跃错题都已个别"掌握"** —— 没有任何一条还在活跃队列中
2. **近 30 天内该节点未再被新错题命中**

满足两个条件时：
- 生成 `总结/专题/<节点>-掌握-YYYY-MM-DD.md`
- 在档案 frontmatter 里把该节点从 `根因图谱` 移入 `已掌握知识点`（如果粒度对得上）

不满足时继续观察。

## 根因图谱的衰减算法

"计数"不能永远涨——否则旧错会一直压着新错的优先级。衰减规则：

- 每次批改**写回前**，遍历 `根因图谱` 的所有节点
- 对每个节点计算**距上次命中的批改数**
- **连续 ≥ 3 次批改未再命中** → 计数 **−1**（最低不低于 0）
- 计数降到 0 → 从 `根因图谱` 中删除该节点（移入 `已掌握知识点`，如果历史上有错题稳固过）

这样既保留近期信号的优先级，又让老的"曾经有过但已克服"的节点自然消退。

## 队列文件结构

在档案根目录下维护一个**单一队列文件**：`_回访队列.md`。

```yaml
---
技能: prism-child-homework
类型: 回访队列
生成时间: {{ISO8601}}
活跃条目数: {{N}}
---
```

正文用 Markdown 表格（**家长能看得懂的自然表头**）：

```markdown
## 正在追踪的题目

| 题目简述 | 来自哪次批改 | 下一次回访日期 | 已做对几次 |
| --- | --- | :---: | :---: |
| ... | [[...]] | YYYY-MM-DD | N/3 |

## 已掌握（最近 10 条）

| 题目简述 | 学会于 | 总共练了几次 |
| --- | --- | :---: |
```

内部字段（`进度: R1~R5`、`连续通过`、`条目 ID`、`根因节点`）存在 frontmatter 的附加字段里：

```yaml
条目:
  - id: "2026-04-18-a"
    知识点: "体积与表面积"
    根因: "维度感知（单位）"
    层级: L5
    来源批改: "2026-04-18-0031-数学"
    下次到期: "2026-04-19"
    进度: R1
    连续通过: 0
```

## 每次批改的强制入队 / 出队流程

### Step 1（载入档案时）

- 打开 `_回访队列.md`，读出所有 `下次到期 <= 今天` 的条目 → **到期列表**
- 若 `_回访队列.md` 不存在，新建空队列（不算首次运行的阻塞项）

### Step 4（生成练习题时）

- 到期列表非空：从中挑 1-2 条，生成针对性**情境变式题**插入当次练习（Markdown 里标 🔁 + 自然语言说明）
- 到期列表 > 3 条：只取**根因图谱中优先级最高**的 2 条，其余顺延一天（下次到期 +1）
- 到期列表为空：不强制；可按根因图谱主薄弱挑 1 条做保险复习

### Step 6（写回 Obsidian 时）

- **新增错题**：为本次新错题在队列追加条目，初始进度 `R1`，到期 `今天 + 1`
- **已回访错题**：
  - 做对 → 进度推进 R1→R2→R3→R4→R5；`下次到期` 更新；`连续通过 +1`
  - 连续通过 3 次 → 从队列删除，追加到 `已掌握` 归档，并在错题本对应条目末尾写"✅ 学会了"
  - 做错 → 重置 `R1`、`下次到期 = 今天 + 1`、`连续通过 = 0`；根因节点命中 +1

### 实操要点

- 回访题的**情境必须变**：数字、容器、物品换一套，避免孩子靠题面记忆
- 回访题在练习题 Markdown 里**标 🔁** + **自然语言**：

```markdown
### 第 3 题 🔁 上次在"体积单位"上卡过，换个情境再试一下

> [!question]
> …题目…
>
> > 来自 [[2026-04-18-0031-数学]] 的错题。
```

## 队列健康指标

每周/月/年报必须报告三个数字（见 `summary-science.md`）：

- **按时处理率** = 按时被处理的到期条目 / 所有到期条目（<70% = 批改频率跟不上）
- **回访做对率** = 回访做对次数 / 总回访次数（<60% = 间隔太长或根因未真正解决）
- **从错到会用了几次** = 进入"掌握"所需的平均批改次数（长期偏高 → 调整教学法，不是题量问题）

## 失败处理

- 孩子长期未上传（≥ 14 天）：到期条目不无限堆积；把 ≥ 14 天逾期的条目重置到 `R1`，在队列顶部加 `> [!warning]` 告知家长
- 一次批改同时触发 ≥ 5 条到期：只处理 2 条（根因图谱高优先），其余顺延，避免练习超载（cognitive load）
- 同一错题在活跃队列中又错：合并，不新增行；`连续通过 = 0`、进度回 `R1`、根因节点计数 +1
