# Metacognition Prompts

本文件是**技能内部**的反思训练操作手册。"元认知"一词仅在本文件和 frontmatter 里出现，**不允许出现在用户可见的正文**（批改记录、错题本、总结）。

- 用户可见的这一节在批改记录末尾叫 **"🪞 我的回顾"**
- 回答质量 L0~L5 rubric 只用于内部长期追踪，不展示给孩子和家长
- 用户可见的质量描述换成自然语言（"起步" / "开始说方法了" / "能讲清楚思路了" / "能看到规律了" / "能举一反三了"）

## 为什么要做这件事

元认知（Flavell 在 1970s 提出，Schoenfeld 1980s 引入数学教学）指"对自己思考过程的感知与调节"。它是数学思维里**区分"会做"和"会学"的分水岭**，是可训练的。

在小学阶段，这种能力**不会自发出现**——孩子需要成年人反复、显性地提问才能内化。这是本技能每次批改末尾都保留 🪞 回顾小节的原因。

## 发展阶段适配

年龄越小，元认知负担必须越轻，否则 cognitive load 会反噬计算本身。按 `pedagogy-by-stage.md` 的阶段分层：

| 阶段 | 提问数量 | 深度 | 回答方式 |
| :---: | :---: | --- | --- |
| A · 一~二年级 | 1 | 只培养"回头看" | 口头即可 |
| B · 三年级 | 2 | 方法意识 | 口头 或 一句话写下 |
| C · 四~五年级 | 3 | Polya 简化版 | 写在批改记录末尾 |
| D · 六年级 | 4 | Polya 完整 + 替代方案 | 写在批改记录末尾 |
| E · 初中 | 5 | Schoenfeld 完整四象限 | 独立段落书写 |

## 各阶段提问模板

### 阶段 A（1-2 年级）

> [!question] 小小回头看
> 你做完再看一遍，觉得这道题对不对？为什么？

**记录方式**：孩子口头回答即可，家长替孩子在批改记录末尾写一句。
**评估重点**：孩子是否**愿意**回头看（不是答得多对）。

### 阶段 B（3 年级）

> [!question] 回头看 + 方法回忆
> 1. 这道题你用了什么方法？
> 2. 这个方法是看到题里的什么词（或画面）让你想起来的？

**记录方式**：孩子口述，家长转写（1-2 句话）；或孩子自己写一句。
**评估重点**：是否能从题目中识别"方法触发线索"，即 schema 的初步显性化。

### 阶段 C（9-11 岁，小学 4-5 年级）

> [!question] Polya 简化版
> 1. 这道题考的是什么知识点？
> 2. 我用了什么公式/方法？公式里的量我都知道吗？
> 3. 我下次遇到同类题，第一眼会注意什么？

**记录方式**：孩子自己在批改记录末尾的「🪞 我的回顾」callout 里作答；家长不代笔。
**评估重点**：
- 问 1：能否说出**上位知识点名**，不只复述题目。
- 问 2：是否意识到"公式里每个量是否已知"这一检查点（比如遇到排水法题 "不能求体积、因为不知道底面积" 这种判断能力）。
- 问 3：是否形成**可迁移的识别线索**，而非复述解法。

### 阶段 D（6 年级）

> [!question] Polya 完整 + 替代探索
> 1. 题目要求什么？用一句话复述。
> 2. 我用了什么方法？为什么选它？
> 3. 中间哪一步最难，为什么？
> 4. 有没有别的做法可以得到同样的答案？

**记录方式**：孩子独立书写。
**评估重点**：
- 问 3 的"难点意识"反映工作记忆瓶颈是否已被识别。
- 问 4 不要求真的做出第二种解法，只需说出"另一种思路方向"。

### 阶段 E（初中）

> [!question] Schoenfeld 四象限（资源/启发/控制/信念）
> 1. 题意是什么？画图或用自己的话重新叙述。
> 2. 我用到了哪些已知（定理/公式/经验），怎么调动的？
> 3. 我卡住过吗？我是怎么控制住自己继续推进的？
> 4. 有没有更简洁或更一般的做法？
> 5. 这道题可以迁移到哪些其他场景或题型？

**记录方式**：独立成段书写，必要时画图。
**评估重点**：问 3、问 5 是 Schoenfeld 认为"专家 vs 新手"的关键分水岭。

## 质量评估 rubric

每次批改在写回档案时，对孩子的元认知回答按如下 rubric 评分（仅用于长期追踪，不反馈给孩子）：

| 等级 | 含义 | 指标 |
| :---: | --- | --- |
| **L0 未回答** | 直接跳过或只写"对"/"错" | — |
| **L1 复述** | 只复述题目或答案 | "这道题是算石头体积" |
| **L2 步骤回忆** | 能列举步骤但没有方法命名 | "先算底面积，再乘高度" |
| **L3 方法命名** | 能说出上位知识点或方法类别 | "用了排水法原理：V = Sh" |
| **L4 归因与线索** | 能说出"为什么用这个方法"、下次识别要点 | "因为题目给了上升高度和底面积…下次一看'排水'我就想到这对量" |
| **L5 迁移意识** | 能指出可迁移场景或替代方法 | "把石头换成土豆、把容器换成圆柱也能用" |

在档案 `元认知成长` 字段里维护**近 30 天的平均等级**。每升一级都是里程碑，需要在月报中专门记述。

## 常见误区

1. **不要把提问变成抽查**。元认知训练是"自言自语"的外化，不是"考你记住没"。如果孩子答得差，不要纠正，只在下次练习时**用同样的问题再问**，逐步拔高。
2. **不要代答**。家长最常犯的错：孩子想了 10 秒没说话，家长忍不住提示。忍住 30 秒。沉默本身是元认知的养料。
3. **不要惩罚 L1 回答**。小学阶段从 L1 到 L3 至少需要 2-3 个月稳定提问才能提升。耐心比正确率重要。
4. **不要把元认知题和数学题混算对错**。元认知回答永远按"态度参与"计，不影响本次正确率。

## 在批改记录里的固定位置

每次批改记录的正文**末尾必须加一个元认知小节**（callout 类型用 `quote` 区别普通内容）：

```markdown
## 🪞 我的回顾（孩子作答）

> [!quote] {{对应阶段的问题块}}
> 1. 这道题考的是什么知识点？
>    → 
> 2. 我用了什么公式/方法？公式里的量我都知道吗？
>    → 
> 3. 我下次遇到同类题，第一眼会注意什么？
>    → 
```

如果是技能初次批改（孩子还没来得及写），把 `→` 留空让家长带孩子现场作答；回来再在技能里做质量评估。

## 在档案里的追踪字段

```yaml
元认知成长:
  当前阶段: C
  近30天平均等级: L2   # L0~L5
  近30天提问次数: 4
  最近一次升级: 2026-04-18  # L1 → L2 的那次
```

## 与其他模块的挂钩

- 若元认知平均等级连续 30 天停在 L1，`summary-science.md` 里的月报要生成"元认知停滞警报"，并建议家长把问题更具象化（比如让孩子画图说思路）。
- 若某道错题回访时孩子的元认知回答升到 L4+，`retrieval-schedule.md` 里可以**加速间隔**：R2 → 直接跳到 R4（表明真懂了，不需要紧间隔）。
- 元认知等级是判断"是否可以跃迁阶段"的关键信号之一（见 `pedagogy-by-stage.md` 的跃迁标准）。
