# Grading Rubric

本文件是**讲解**的统一口径——讲解风格、详细度、语言边界、知识点命名。深层的错题分类（Newman 层级 + 概念根节点）在 `error-taxonomy.md`。两者必须同时使用。

## 两层语言边界（与 `language-conversion.md` 对齐）

- **内部层**（frontmatter、tags、聚合统计）：允许用 `层级 L1~L5`、`根因节点`、`Newman` 等术语
- **用户可见层**（批改正文、错题本正文、🪞 回顾、周月年报正文）：**禁用术语**，用自然中文

错误类型放到 frontmatter 的 tag 里，正文用自然中文描述错在哪。

## 用户可见的问题分类

给孩子和家长看的时候，把错归到四类（而不是内部的 5 层）：

| 用户分类 | 内部对应层级 | 例子 |
|---|:---:|---|
| **题意没看清** | L1 读题 + L2 理解 | 把"多"读成"少"、漏条件、不理解题目在问什么 |
| **想错** | L3 转换 | 该用 V=Sh 却列了 V=abc |
| **算错** | L4 策略/执行 | 小数进位漏、分数通分错 |
| **写错** | L5 编码 | 算对了但单位漏、答案抄错 |

在批改记录的"逐题速览"表里，**问题类型** 一栏填这四类（不填 L1~L5）。

## 讲解骨架选择（按模式）

讲解详略取决于档案里的 `输出模式` 字段：

- **完整模式**：每道错题按**六模块骨架**展开（见下）
- **简洁模式**：每道错题按**三块骨架**展开：
  1. **为什么错**（一两句，直击卡点）
  2. **关键规则**（单位换算 / 核心公式 / 识别信号，用 code block 或短列表）
  3. **3 道验证练习**（同类 1 + 变式 1 + 稍进阶 1）+ 折叠答案

简洁模式骨架见 `summary-templates-concise.md`。以下是**完整模式**的六模块细则。

## 完整模式 · 六模块详细度（按年龄阶段）

每道**错题**的讲解正文必须覆盖**六个模块**。深度按年龄阶段调整——详细分级见 `pedagogy-by-stage.md`，此处给出公共骨架：

### 模块 1 · 为什么错（诊断）

- **必须**：指出真正的卡点，用孩子能理解的语言
- **避免**：只说现象（如"你写成 cm² 了"），要说现象背后的原因（如"你脑子里还没把'这是几维'和'单位要几次方'这两件事锁在一起"）
- **避免**：用"你常粗心"这种标签

字数按阶段：A 阶段 1 句、B 阶段 1-2 句、C 阶段 2-3 句、D 阶段 3-4 句、E 阶段可展开更深。

### 模块 2 · 正确做法（步骤）

- **必须**：每步写清楚 + 为什么这步要这么做
- C 阶段及以上：用**表格**形式呈现（步骤 / 算式 / 单位 / 为什么）
- 尽量用具象元素锚定（"因为每面是 3×3 的小正方形"）

步骤数按阶段：A 2-3 步、B 3-4 步、C 4-5 步、D 4-6 步、E 按需。

### 模块 3 · 举一反三（泛化）

- **必须**：给 1-N 个类似的题型或情境，让孩子看到规律
- **必须**：给"识别信号"——下次看到什么词 / 什么情境应该想到这个方法
- 变式数量按阶段：A 1 个、B 1-2 个、C 2-3 个、D 2-3 个（含跨情境）、E 2-3 个（含跨题型）

### 模块 4 · 容易混的地方（辨析）

- **必须**：指出最容易混的 1-2 个近邻概念，并给出辨别点
- **例**：面积 vs 体积的辨别点是"有几个维度在相乘"
- A 阶段此模块省略（认知负荷太大）；B 阶段只提一个最直接的；C 及以上必写

### 模块 5 · 小口诀（记忆，可选）

- 有简单押韵的口诀就给一句；没有就略过
- **例**："两维平方，三维立方"、"分母通一通，加减才轻松"

### 模块 6 · 知识点延伸（关联）

- **必须**：指出这道题在课本哪个单元、对应大概念是什么
- C 阶段及以上：加一句"上一章学的 X 正好在这里用到"、"后面学 Y 时会用同一个思路"
- 帮孩子建立知识网络感，不孤立看题

## 讲解语气（按年龄）

从 `pedagogy-by-stage.md` 精炼：

| 阶段 | 人称 | 语气特征 | 步骤颗粒度 |
|:---:|:---:|---|:---:|
| A · 6-8 岁 | 第二人称 | 极简、故事化、每步都具象 | ≤ 3 步 |
| B · 8-9 岁 | 第二人称 | 引导发现，"我们一起想" | 3-4 步 |
| C · 9-11 岁 | 第二人称 | 半引导半挑战，允许"先自己想想" | 3-5 步 |
| D · 11-12 岁 | 第二人称为主 | 挑战 + 反问 | 3-5 步 + 替代方案 |
| E · 12-15 岁 | 平等同伴 | 问题式、证明意识 | 按题而定，含推理 |

通用要求：

- 面向孩子而不是家长，称呼用第二人称
- 不用"这很简单"、"你怎么还错这个"等评判语
- Growth Mindset 语言：错题是"正在长的肌肉"，错误是"好机会，刚好看见缺口"
- 命中既有概念节点时，正文用自然语言点出"这块上次也出过问题"，并 wikilink 到旧条目

## 正确题的点评（模块 2 块）

每道正确题必须写：

**块 1 · 做得好的点**
- 具体指出哪一步思路对（不说"很棒"、"真聪明"这类空话）
- 例：不说"你做对了"，而说"你看到'石柱高 4m' 和 '池深 2m'，马上想到石柱只有 2m 浸水——这一步很关键"

**块 2 · 知识点延伸**
- 这道题考的是什么概念、在哪个单元
- 核心概念一句话
- 下一步加难度会往哪些方向变

## 知识点命名（正文用这个，不用"根因节点"）

**区分**：

- **知识点** = 课标章节级的名称，正文和错题本文件名用这个（`错题本/数学/体积与表面积.md`）
- **概念根节点** = 跨知识点的深层概念（如"维度感知"跨越面积、体积、进率）——只在 frontmatter 和技术讨论里用

### 小学低年级（一~二年级）
- `数的认识`、`加减法`、`乘法口诀`、`表内除法`
- `长度与质量`、`时间与人民币`
- `简单图形`、`对称`

### 小学中年级（三~四年级）
- `多位数乘除法`、`运算顺序`
- `分数初步`、`小数初步`
- `周长与面积`、`角与三角形`

### 小学高年级（五~六年级）
- `分数运算`、`小数运算`、`百分数`
- `比与比例`、`正反比例`
- `行程问题`、`工程问题`、`鸡兔同笼`
- `圆与扇形`、`体积与表面积`
- `简易方程`

### 初中（七~九年级）
- `有理数与绝对值`、`整式运算`、`因式分解`
- `一元一次方程`、`二元一次方程组`、`不等式`
- `函数与图象`（一次、反比例、二次）
- `三角形全等与相似`、`四边形`、`圆`
- `概率与统计初步`

命名规则：
- 一律使用上表中出现过的词条，避免生造
- 跨多个知识点的题：主标签选**最直接导致错误**的那个
- 错题本文件**一个知识点一份**

## 正确率与难度判定

`近 30 天正确率`：

```
近30天正确率 = Σ(正确 + 0.5 × 部分正确) / 题目总数
```

- 部分正确按半题计分
- 不足 5 道题不更新此指标
- 每周周报重新计算；年报列 12 个月的月度正确率表

**难度判定**（原 ZPD，用户可见时用"题目难度"）：

| 连续 3 次正确率 | 判定 | 下一周期动作 |
|:---:|---|---|
| > 0.90 | **偏简单** | 上调难度，引入下一阶段的变式 |
| 0.60~0.85 | **刚合适** | 保持 |
| < 0.55 | **偏难** | 回落到具象 / 基础概念 |

正文里用"偏简单 / 刚合适 / 偏难"这三个说法，不用 "ZPD"。
