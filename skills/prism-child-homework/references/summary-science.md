# Summary Science

本文件是**周 / 月 / 年总结的评估框架**——技能内部的规格文件。用术语（Schema、ZPD、元认知、Retrieval）方便规格描述；**具体的 Markdown 模板和正文措辞全部由 `summary-templates.md` 定义，不在本文件重复**。

用户可见的四个维度的自然语言名称：

| 内部名称 | 用户可见章节标题（见 `summary-templates.md`） |
|---|---|
| Schema 成长 | "🌱 这周学会了什么 · 还在挣扎什么" |
| ZPD 漂移 | "📐 题目难度是否合适" |
| 元认知深度 | "🪞 回顾习惯" |
| Retrieval Mastery | "🔁 长期记得住多少" |

---

## 维度 1 · Schema 成长

**评估输入**：`孩子档案.md` 的 `根因图谱`、活跃错题本、回访队列中已掌握的条目。

**评估产出**：把每个概念节点归到三档：

- **已掌握（稳固节点）**：满足 `retrieval-schedule.md` 的"整体掌握"判定（所有活跃错题都稳固 + 30 天内未新命中）
- **挣扎节点**：本周期新增错题 ≥ 3 次 或 回访重置 ≥ 2 次
- **新浮现节点**：本周期首次出现

## 维度 2 · ZPD 漂移（难度是否合适）

**评估输入**：本周期所有批改的正确率序列。

**评估规则**（Vygotsky / Bjork 的 desirable difficulty）：

| 情况 | 判定 | 建议 |
|---|---|---|
| 连续 3 次批改正确率 > 0.90 | **低于 ZPD**（题目偏简单）| 难度应提档。给下周更复杂的变式或跨学期题 |
| 连续 3 次 0.60~0.85 | **ZPD 恰好** | 保持 |
| 连续 3 次 < 0.55 | **超出 ZPD**（题目偏难）| 难度需回落。回到基础概念具象化 |
| 波动大（> 25% 振幅）| **规律不稳** | 看是否跟题型切换相关；可能是概念跳跃过大 |

## 维度 3 · 元认知深度

**评估输入**：本周期每次批改中孩子在 🪞 我的回顾 小节的回答，按 `metacognition-prompts.md` 的 L0~L5 rubric 打分。`孩子档案.md` 中的 `反思成长.近30天平均等级`。

**评估规则**：

- 平均等级较上周期 **+0.5** 及以上 → 升级证据明显 → 表扬 + 指出一个下一步挑战
- 周期内无明显升降 → 不施压，继续用相同提问
- 连续 2 个周期都在 L1 → **"元认知停滞警报"**：建议家长换提问方式（画图说、同伴讲、对家长讲课）

## 维度 4 · Retrieval Mastery

**评估输入**：`_回访队列.md` 当期的条目流动数据 + 每次批改回访题的对错记录。

**评估产出**：

- **按时处理率** = 按时被处理的到期条目 / 所有到期条目
- **回访做对率** = 回访做对次数 / 总回访次数
- **从错到会用了几次** = 从入队到标"已掌握"的平均批改次数

**评估规则**：

| 指标 | 健康区间 | 不健康的解读 |
|---|:---:|---|
| 按时处理率 | ≥ 80% | 批改频率跟不上；家长需要提醒节奏 |
| 回访做对率 | 60%~80% | <60% = 间隔/方法未匹配；>90% = 变式不够，被"背下来"了 |
| 从错到会用了几次 | 3~5 次批改 | 偏慢说明根因未触达；偏快可能是假稳固（变式太浅） |

## 在总结正文里的呈现

**以上每个维度最终都要在总结里有一段**，但**不在本文件给 Markdown 示例**。具体章节标题、排版、语气全部以 `summary-templates.md` 的周报/月报/年报模板为准——避免两处重复容易不同步。

规格与模板的分工：
- 本文件（`summary-science.md`）= **评估逻辑 + 判定阈值**（技能内部决策用）
- `summary-templates.md` = **Markdown 输出格式 + 措辞**（写到文件里的）

## 特殊触发的总结文件

### 专题总结（概念整体掌握时追加）

触发条件见 `retrieval-schedule.md` 的"概念节点整体掌握的判定"。生成 `总结/专题/<知识点>-掌握-YYYY-MM-DD.md`。模板在 `summary-templates.md`。

### 里程碑（反思跃迁时追加）

触发：反思平均等级首次跨过新的 L 边界（L0→L1、L1→L2、…）。生成 `总结/里程碑/反思-YYYY-MM-DD.md`。模板在 `summary-templates.md`。

### ZPD 持续警报

连续 3 周 ZPD 判定为"低于"或"超出" → 在下一次批改的回应中**显式提醒家长**整体难度需要调整。不生成单独文件，只在批改正文的"整体情况"里加一行。

---

## 无数据周期的处理

周 / 月 / 年无批改时仍要生成总结文件，内容仅含"本周期无数据"占位 + 节奏提醒。不编造数据。模板在 `summary-templates.md`。

## 多周期缺失补齐

若用户长时间未上传（例如 3 周没来）：

- 按 SKILL.md Step 7 的规则**逐级补齐**：先按时间正序补所有缺失的周报，再补月报，再补年报
- 每份总结独立生成一张配图
- 无数据周期用占位文件（不留空）
- 在最新一份周报顶部加一条提醒"过去 X 周没有批改数据，连续性受损"
