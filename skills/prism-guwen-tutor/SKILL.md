# prism-guwen-tutor

## Overview

面向 **初中学生（初三标准）** 写古诗文详解。用户给出一个 Obsidian 定位条件（目录 / 文件路径 / 作者 / 作品名），技能在 vault 里找到需要讲解的原文，按 **7 模块框架** 生成一份独立的兄弟文件 `<原名>-详解.md`。

**难度统一为初三**——不论原文是小学课本、初一课本还是高中必修的作品，讲解一律按初三的用词深度、注释密度、手法展开程度来写。这样学生拿到任何一篇都有稳定的深度预期，也避免 skill 做错误的难度派生。

核心设计原则：

- **进入—深入—跳出的三段弧**，不是"字词+翻译+中心思想"的小学三板斧。
- **节制优于详尽**：一篇只精讲 2–3 个点，不罗列八个浮在表面的观点。
- **诗与文权重不同**：诗重声音/意象/普遍经验，文重叙事逻辑/句式/思想延伸。
- **人称用"你"**，避免"我们""作者表达了…的思想感情"这类教师腔和套话。
- **古人和现代学生之间是活的**：把作者还原成一个具体的人，不是头像。

本技能 prompt-first。定位、判读、讲解全部由 Claude 自身完成；所有 vault 读写通过 `obsidian-cli` 技能，写入前通过 `obsidian-markdown` 技能校准排版。

## When to Use

触发这个 skill 的典型场景：

- 用户给出一个 **Obsidian 定位**（目录 / 文件 / 作者 / 作品名）并要求"讲解 / 详解 / 写一份赏析 / 给初中生讲一下"
- 用户指着教材里的某一单元说"把这些都讲一遍"
- 用户提到一个作者（如"苏轼""王维"）希望批量处理该作者 vault 内尚未讲解的作品
- 用户明确说"偏审美 / 偏应试"让你调整 focus（难度固定为初三，不可调档）

不要用于：

- **非古诗文的现代语文内容**（现代诗、散文、小说）——停下来拒绝
- **和 vault 无关的一次性问答**（例如对话中粘一首诗问"这什么意思"）——直接答即可，不写文件

**小学阶段作品的说明**：如果用户让讲一年级到六年级的作品，**照常按初三标准写**（技能的职责就是把所有作品统一到初三深度）。用户可能在为初中孩子做复盘或拔高，不要反复询问"是否降档"。

### 触发短语（示例，不要求精确匹配，句意等价即可）

| 意图 | 常见触发 | 动作 |
|---|---|---|
| 讲单篇 | "讲一下这首《登高》"、"把这篇《陋室铭》写一份详解" | 定位单文件 → 走完整 Workflow |
| 讲目录 | "把必修上里所有古诗都讲了"、"七年级上的文言文全写一遍" | 目录递归 → 过滤 → 批量 |
| 讲作者 | "苏轼的几首都写一下"、"所有杜甫还没讲的" | 搜 frontmatter.`作者` → 列候选 |
| 按名字找 | "讲一下《春望》" | 搜 frontmatter.`标题` / 文件名 → 若重名则列候选 |
| 强制重写 | "《登高》那篇重写" / "--force" | 跳过"已存在则跳过"的幂等保护 |
| 调侧重 | "偏审美""偏应试" | 覆盖默认 focus（难度固定初三，不接受改档请求） |

## Hard Constraints

### 读者年龄（最高优先级 · 凌驾所有其他规则）

**目标读者固定为 12–14 岁的初中生**——这是本 skill 的第一假设，也是所有其他规则的上位约束。

**内容对学生无害是第一标准**。任何优美、深刻、聪明的写法，只要不适合这个年龄段，都必须让路。当某一段无法在保持无害的前提下写好——**删掉它**。宁可少讲一层，不可多讲一句不该讲的。

**硬性禁止（发现即重写）**：

- **粗俗口语与网络黑话**——例："装孙子""打脸""吊打""社死""破防""yyds""emo""拿捏"（成人化的"掌控"义）等。
- **双关 / 隐喻含成人色彩**——特别警惕"让某某抬不起头""某某的男人/女人"这类结构。涉及古代酷刑（腐刑 / 宫刑）时用"古代最重的酷刑之一"带过，**不**做身体层面的展开。
- **成人化处世学 / 算计术语**——"话术""账本""酒局""人脉经营""伏低装弱""留后手""给自己留退路"等会把学生引向功利视角的词。
- **黑色 / 世故的世界观总结**——"人心不变，局就一直是同一张局""都是一场交易"这类阴郁的人生定论。**结尾要留光**。
- **对暴力 / 酷刑 / 死亡的细节渲染**——历史事实（自刎、处刑、杀戮）**一句客观叙述带过**，不展开过程、不具象化。
- **模仿性的权谋教学**——讲历史人物的政治手段时，立场是"历史是这样发生的"，不是"你将来也要这么做"。不要在"为什么这篇能留下来"里把学生带向"职场预演 / 饭局策略"。

**价值落点的正确方向**——从人物 / 历史讨论出发，回到**人性共通点**（友谊、判断力、诚信、责任感、勇气、怎么面对失败），而不是**社会生存术**（怎么应付上级、怎么在饭局上占便宜、怎么看穿人心）。

古人和当代学生之间的连接是"共通的人"，不是"共通的局"。

具体禁用词清单、双关识别、价值落点示例详见 `references/explanation-framework.md` 的「12–14 岁年龄适配准则」章节。

### 输出位置（核心）

- 详解文件**只**落在原文件的兄弟位置：`<原文件所在目录>/<原文件名 stem>-详解.md`
  - 例：原文 `教育/教材/语文/古文诗词/古诗/必修上/07-登高.md` → 详解 `教育/教材/语文/古文诗词/古诗/必修上/07-登高-详解.md`
- **不修改原文件**。原文件可能已经包含译文、注释、名家讲读等内容，保持原样。
- 详解文件用 wikilink 指回原文（`[[07-登高]]`）；原文件里不主动加反向链接（避免污染）。
- 命名严格遵守 `-详解.md` 后缀——判定"是否已讲解"只看这一个规则。

### 讲解结构（7 模块 + 1 可选，顺序与权重）

每篇详解必须覆盖以下 7 个模块，顺序固定。各模块权重按**文体**调整（诗/词 vs. 文言文），详见 `references/explanation-framework.md`：

1. **一句话钩子 Hook**：反直觉问题 / 现代类比 / 戏剧性场景开场，让学生在读正文前就想知道。
2. **作者此刻 Author in the Moment**：写作当下那个具体时刻（年龄、地点、刚经历什么、心里在想什么），**不是**生平简介。
3. **原文 + 诵读提示**：完整原文 + 节奏/停顿/韵脚标注（诗）或长句断句（文言）+ 一句诵读建议。
4. **逐层拆解 Close Reading**：按 2–4 句一组的意义单元分块；每组只做三件事——字面在说什么（简明翻译不堆砌）、哪个字是诗眼/关键转折及其原因、本组在整体中的功能（铺垫/转折/收束）。**全篇只精讲 2–3 个点**。
5. **手法与结构 How it Works**：挑 1–2 个本篇最突出的手法讲透（对仗、意象、虚实、视角、文言句式等），**不要列清单**。callout 仅作为"模块开场锚点"或"末尾金句"使用——**不要把整个模块都塞在一个 `[!tip]` 里**，讲解主体应走普通段落。
6. **为什么这篇能留下来 Why it Endures**：讨论本篇触及的**普遍人性经验**（落在"人"，不落在"局"），不讲"中心思想"、不用"表达了作者…的思想感情"。
7. **延伸与挑战 Go Further**：1–2 个开放性问题或对比阅读，**不要标准答案**。

#### 可选第 8 模块 · 🍵 大师漫谈

仅在以下条件**都**满足时开启：

- 作品有**公认的名家评点或文学史讨论**，且有真实可查的原文/条目。
- 文体是**文言散文或长诗/词**；短绝句一般不开。
- 用户 `focus` 包含 `文化`，或作品文化分量足（《鸿门宴》《岳阳楼记》《出师表》级别）。

本模块的硬约束：

- **全程第三人称**——严禁伪托"某某先生说——"的第一人称扮演。原因：①多数情况下会滑向编造；②学生会误以为是大师原话；③即便不编造，也在灌输"我在替大师代言"的虚假权威。
- **每条引用可核查**——优先**真实原文直引**（鲁迅"史家之绝唱，无韵之离骚"这类可查的金句），次选学界公认条目（赵翼《廿二史札记》"汉初布衣将相之局"）。**不确定就不写**——宁可模块更短，不要充数。
- **连贯主线叙事**——不拆 `###` 子标题，整段像一条河用过渡词顺下来（避免"六小节拼贴"式的零散）。
- **引文用 `[!quote]` callout 做节拍器**，正文走普通段落做解读——骨肉分明，视觉上"大师一句→你一段→大师一句→你一段"。
- **不与模块 5 撞车**——模块 5 讲笔法手法，模块 8 讲文学史 / 历史背景 / 文化传承，互不重叠。

**关闭本模块的判断**：没有把握找到 ≥2 处真实可查的名家引文 → 不开，不勉强。"开错了"比"不开"伤害大——伪托比缺席更坏。

写作细节见 `references/explanation-framework.md` 的「模块 8 · 大师漫谈」章节。开启本模块时，全篇总字数放宽到 2200–3200。

### 长度与排版

- **总字数 1500–2500 字**。再长学生读不完，再短讲不透。
- **段落不超过 4 行**，每段一个主意思。
- 每个模块用 Obsidian callout 开头作视觉锚点（具体 callout 类型见 `references/explanation-framework.md`）。
- 原文引用用 `[!example]`；点睛金句用 `==高亮==`；单字/词用 inline code。
- **不使用 LaTeX**（`\t`/`\n` 开头的命令会被 `obsidian-cli` content 参数破坏）；注音和少量符号用 Unicode。

### 语言与语气

- **第二人称"你"**为主，偶尔"咱们"。**禁用**"我们""作者表达了 XX 的思想感情""这首诗的中心思想是""本诗运用了 XX 的手法"。
- 允许轻微口语化和幽默；**不讨好、不油腻**（不要"哈哈""绝了""破防了"这类网络词）。
- 学术术语（"互文""用典""借景抒情""判断句"）可以出现，**第一次出现时必须附一句不超过 20 字的解释**。
- 不出现"12–16 岁""初中阶段""这个年龄段"这类元描述——别提醒学生你在教他们。
- 正文一律用中文。

### 已存在保护

- 默认**幂等**：目标位置已存在 `-详解.md` → 跳过，并在最终回应里列出被跳过的文件。
- 用户显式说 `--force` / "重写" / "覆盖" → 走 `obsidian create overwrite`。

### 定位候选消歧

- 输入是**作者**或**作品名**命中多个文件 → **阻塞式**列出候选（含路径、年级、朝代），让用户选择；禁止默认"全选"批量，避免误操作。
- 输入是**目录**命中 N 个未讲解文件 → 先列出全部候选 + 预估生成时长，让用户确认后再批量。
- 候选 0 个 → 停下来告知，建议检查路径或扩大搜索范围。

### 不处理的内容

- 识别到**现代汉语**文本（现代诗、小说、课文中的现代散文）→ 明确拒绝并告知本 skill 只处理古诗词 / 文言文。
- 识别到**多篇合并**在同一文件 → 停下来问："这份文件里有 N 篇，分开写还是合并写？"
- 识别到**原文严重残缺 / 无法辨认**→ 请用户补齐后再处理。

## Runtime Policy

- 依赖 `obsidian-cli` 技能（命令行入口就是 `obsidian`），必须可用；否则终止并告知。
- 依赖 `obsidian-markdown` 技能校准排版；写入前调用。
- Vault 根与搜索基准目录解析优先级：
  1. 用户当前对话中显式提供的绝对路径
  2. 环境变量 `GUWEN_TUTOR_VAULT_ROOT`（vault 绝对路径）和 `GUWEN_TUTOR_BASE_PATH`（基准相对路径，默认 `教育/教材/语文/古文诗词/`）
  3. `obsidian vault` 命令查询到的 vault 根 + 默认基准路径
  4. 若三者都不可解析 → 阻塞式询问
- **首次运行无需建档**：本 skill 无持久配置，运行时参数完全从输入和环境变量派生。
- 批量任务一次处理上限 **5 篇**；超过时分批确认，避免长响应打断。

### 环境变量

| 变量 | 含义 | 未设置时的行为 |
|---|---|---|
| `GUWEN_TUTOR_VAULT_ROOT` | Obsidian vault **绝对路径** | 回退到 `obsidian vault` 查询结果 |
| `GUWEN_TUTOR_BASE_PATH` | 相对 vault 的搜索基准目录 | 回退到 `教育/教材/语文/古文诗词/`（当前 vault 惯例） |

shell 命令引用时统一写 `"$GUWEN_TUTOR_VAULT_ROOT"` / `"$GUWEN_TUTOR_BASE_PATH"`；不要写死任何个人机器路径。

### 侧重与开关（参数）

难度**不**作为参数暴露——全部作品一律按 **初三标准** 写作。初三档的用词、注释密度、手法展开深度、字数范围等写作参数见 `references/explanation-framework.md` 末尾的「初三档写作参数」章节。

| 参数 | 取值 | 默认 |
|---|---|---|
| `focus` | 审美 / 应试 / 思辨 | "审美 60% + 应试 40%"，思辨始终注入但不挂主标签 |
| `force` | true / false | false |

用户自然语言覆盖即可，例如"偏审美""这篇重写"，不必要求 CLI 风格写法。

如果用户明确要求改难度档（"按初一讲""讲浅一点"）——**礼貌拒绝**，解释本 skill 固定初三档，建议对方改为"偏审美"或"偏思辨"（这些 focus 参数已经能提供相当大的风格差异）。

## Workflow

### Step 1: 解析输入条件

用户输入可能是四类之一——判别并归一化：

| 输入形态 | 判别信号 | 归一化结果 |
|---|---|---|
| 绝对/相对**文件**路径 | 末尾 `.md` 且存在 | 单文件列表 |
| 绝对/相对**目录**路径 | 结尾 `/` 或不含 `.md` 且是目录 | 递归目录列表 |
| **作者**名 | 单独的中文名（2–4 字常见），无路径分隔符 | 走 Step 2 的 frontmatter `作者` 搜索 |
| **作品**名 | 带书名号 `《》` 或与已知作品库匹配 | 走 Step 2 的 frontmatter `标题` / 文件名搜索 |

歧义时（例如"登高"既是作品名也是目录名）→ 先试作品名搜索，命中 0 再试其他形态。

### Step 2: 定位候选文件

- **文件输入**：直接得到单文件候选。
- **目录输入**：用 `obsidian ls` 或文件系统递归列出 `.md`，过滤掉以 `-详解.md` 结尾的文件。
- **作者输入**：用 `obsidian search query="作者: <名>"` 在基准目录下搜 frontmatter。
- **作品名输入**：用 `obsidian search query="标题: <名>"`；若命中 0 再按文件名模糊搜。

过滤规则：

- 排除 `-详解.md` 结尾文件本身。
- 识别 frontmatter `类型` 字段：只保留 `古诗 / 词 / 文言文`；`古文言文` 等近邻值也接受。
- 已有兄弟 `-详解.md` 且未 `--force` → 标记为"跳过"，不进入生成集合。

### Step 3: 候选确认（可能阻塞）

- 候选数 = 0 → 停下来告知并建议如何调整。
- 候选数 = 1 → 继续，不阻塞。
- 候选数 ≥ 2 且输入是作者/作品名 → **阻塞式**列出候选表让用户选：

  ```
  我在 vault 里找到这些和"杜甫"相关的、还没写详解的作品：

  1. 《春望》— 人教七下/10-春望.md
  2. 《登高》— 必修上/07-登高.md
  3. 《茅屋为秋风所破歌》— 人教八下/24-茅屋为秋风所破歌.md

  你希望讲哪几篇？（回复序号或"全部"）
  ```
- 候选数 ≥ 2 且输入是目录 → 列出候选 + 总数 + 预估，让用户 `确认 / 去掉某些 / 只做前 N 篇`。
- 单次批量上限 5 篇；超过时分批。

### Step 4: 读原文并识别元信息

对每篇候选：

1. `obsidian read path="<相对路径>"` 拿到 frontmatter + 正文。
2. 从 frontmatter 提取：`标题 / 作者 / 朝代 / 年级 / 类型`；缺失字段从正文或文件名回填。
3. 正文中定位**原文块**——通常在 `## 原文` / `[!example]` callout 之下；若没有明确标记则取 frontmatter 下第一块**中文古文片段**。
4. 识别文体：`类型` 字段优先；缺失时由 Claude 判断（诗 / 词 / 文言散文）。
5. `focus` 参数：如用户显式指定则用指定值，否则用默认"审美+应试"。难度档固定初三，**不做派生**。

### Step 5: 生成详解（7 模块）

读 `references/explanation-framework.md` 拿到每模块的写作指引、诗/文权重、以及末尾的「初三档写作参数」；读 `references/style-guide.md` 拿到语气、用词、避坑清单。

写作顺序按模块 1→7。每写完一节自检：

- 是否出现了禁用词（"我们""思想感情""中心思想""表达了……"）？
- 全篇字数是否落在 1500–2500？
- 是否"面面俱到"了？如果是，砍到 2–3 个精讲点。
- 诗/文的权重是否正确？

对照 `references/samples/` 下的样例（《登高》= 诗样例，《陋室铭》= 文样例）做**风格锚定**；不要机械抄结构，样例只是"深度和节奏"的参考。

### Step 5.5: 年龄对齐复核（独立 pass · 不可跳过）

写完初稿之后，**独立跑一遍**这份检查——不是和 Step 5 的风格自检合并，而是**再单独过一遍**，焦点只有一件事：**这段文字给 12–14 岁学生读合不合适**。

逐段过，每句话问五个问题：

1. **有没有粗口或网络黑话？** 例："装孙子""打脸""破防""yyds""吊打""社死" → 改成中性表达。
2. **有没有双关 / 隐喻带成人色彩？** 例："让一个男人再也抬不起头"、"某某的男人"、"每次敬酒都藏着账本"、"酒局社交学" → 拆掉双关，只留字面义。
3. **有没有教成人处世学的句子？** 例："你将来也要学会 XX""这就是社会""学会话术""人脉是最重要的" → 删或改成**人性讨论**（诚信、判断力、友谊、面对失败）。
4. **有没有渲染暴力 / 酷刑 / 死亡的细节？** 例：腐刑如何执行、刎颈过程的具体描写 → 压到**一句客观陈述**。历史事实客观说即可，不具象化。
5. **结尾 / 模块收束句有没有给出灰暗的人生定论？** 例："人心不变""局都是一样的""都是一场交易" → 换成开放的、指向人性的、**留光的**落点。

**这一步必须显式执行**——即使 Step 5 写得很流畅也要独立过一遍。Step 5 的"读得顺"和这一步的"年龄适配"是两件事——前者的流畅往往会悄悄带入后者的越界（一句"要跑就跑，要装孙子就装孙子"在叙事节奏上很漂亮，但在年龄对齐上是硬伤）。

**发现越界的处理**：

- 能就地替换的就替换（例："话术" → "言辞" / "说法"；"装孙子" → "低姿态"；"人心不变" → "人性是相通的"）。
- 改不动的就删。
- 整段无法挽救就**重写该段**——不迁就原稿写得"顺"。

复核完成后内部记录一句"年龄对齐 pass 已完成（修正 N 处）"，再进入 Step 6。

### Step 6: 校准排版并写入

1. 通过 `obsidian-markdown` 技能校准排版：callout 类型、highlight、inline code、wikilink 短名（`[[07-登高]]` 不带路径）。
2. `obsidian create path="<原目录>/<原 stem>-详解.md" content="<Markdown>" silent`（`--force` 时加 `overwrite`）。
3. 如果 content 过大导致失败 → 先落到 `tmp/<stem>-详解.md`，再用 `cp` 放进 vault。

### Step 7: 回应用户

- 列出：本次新生成的详解文件（wikilink 形式）、因已存在而跳过的文件、因无法识别而未处理的文件。
- 挑其中一篇，给出 1–2 句 "本篇精讲的两个点"，让用户知道你选了什么角度。
- 如果有候选数 ≥ 2 的阻塞询问尚未处理，结尾留"待补充信息"。

## Failure Handling

- `obsidian-cli` 不可用 / Obsidian 未启动 → 停止并告知。
- 原文件读不到 / 路径错误 → 列出候选失败原因，建议检查路径大小写或特殊字符。
- 原文件中**找不到古诗文原文块** → 询问用户该文件的原文在哪一段，不要猜测。
- 文体判断不确定（近体诗 vs 古体诗、骈文 vs 散文等）→ 详解 frontmatter 标最接近的值，在 `🎨 手法与结构` 段简述本篇处在哪个交界。
- 生成结果字数失控（< 1200 或 > 3000）→ 不直接写回，先在 `tmp/` 留底再重写。
- `obsidian-markdown` 校准失败 → 二次调用；仍失败则以原样写入并在回应里标红告知。
- 批量任务中某篇生成失败 → 不阻塞其他篇，最终回应里单独列出失败项与原因。
- 用户在阻塞询问时未响应就发来新指令 → 默认放弃上一轮批量，处理新指令。

- `references/obsidian-workflow.md` — `obsidian-cli` 调用范式、搜索查询写法、大文件后备方案
- `references/samples/登高-详解.md` — 诗样例（杜甫《登高》，初三+审美）
- `references/samples/陋室铭-详解.md` — 文言文样例（刘禹锡《陋室铭》，初三+兼顾）
- `tmp/` — 临时产物；不进入 vault
