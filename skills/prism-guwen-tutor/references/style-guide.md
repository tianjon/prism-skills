# 风格指南

## 为什么单独有这份文档

讲解好坏的差距，80% 在风格细节。同一个知识点，一种写法让学生走神，另一种能让学生记一辈子。这里把风格规则集中列出，写详解时做**硬性对表**。

## 人称与语气

**使用**：第二人称"你"，偶尔"咱们"（表示"我陪着你想"）。

**禁用**（每条都有理由）：

- **"我们"** —— 教师腔最典型的标记，让学生立刻产生"被集体训话"的警觉。
- **"同学们"** —— 课堂广播腔。
- **"诗人""作者"开头每一段** —— 听起来像介绍陌生人。讲过一次名字后，更多时候用"他/她"或直接省略主语。
- **"本诗""本文"** —— 公文腔。改用"这首""这篇"。

## 禁用短语清单（发现一个就重写那句）

- "这首诗（这篇文章）表达了诗人（作者）…… 的思想感情"
- "这首诗（这篇文章）的中心思想是……"
- "本诗运用了……的修辞手法（写作手法）"
- "告诉我们要……"
- "启示我们……"
- "歌颂了……""赞美了……""批判了……""鞭挞了……"
- "……的代表作之一""……的杰出代表"
- "唐代著名诗人 XX"（可改为"XX 写这首的时候"）
- "深深地感受到……""强烈地表达了……"
- "字字珠玑""千古绝唱""脍炙人口""流芳百世"（陈词烂调）

为什么禁用？——这些词是**考试答题模板**的残留，学生对它们有"免疫反应"，听到就进入走神状态。

## 12–14 岁年龄适配禁用（最高优先级）

本条目**优先于所有风格追求**。发现一个就改，改不动就删，整段改不动就重写——不迁就"写得顺"。详细准则见 `explanation-framework.md` 的「12–14 岁年龄适配准则」章节；下面只列最常踩的坑：

### 粗俗口语 / 网络黑话（绝对禁）

`装孙子`、`打脸`、`吊打`、`社死`、`破防`、`yyds`、`emo`、`拿捏`（成人化的"掌控"义）、`整活`、`上桌`、`局`（作为成人江湖用语）。

### 成人化处世学（绝对禁）

`话术`、`账本`、`酒局`、`人脉`、`伏低`、`装弱`、`留后手`、`给自己留退路`、`算计`、`博弈`、`心机`、`套路`（作为成人贬义）、`KOL 打法`、`MVP 打手`。

这些词会把学生引向"古人在教我处世术"的视角。古文里发生了算计 → 客观叙述即可；不要把叙述语言本身染上"江湖老手的语气"。

### 黑色 / 世故的人生定论（绝对禁）

`人心不变，局就一直是同一张局`、`这世界就是 XX`、`都是一场交易`、`谁都一样`、`人都是 XX 的动物`。

**结尾要留光**——给初中生的讲解收束必须是**开阔的 / 有人性温度的 / 开放的**，不能是阴郁的定论。

### 双关 / 隐喻带成人色彩（绝对禁）

特别警惕`让一个男人再也抬不起头`这种结构——表面是讲古代酷刑，隐含性暗示。涉及腐刑 / 宫刑 → 用"古代最重的酷刑之一"带过，不做身体层面展开。

### 暴力 / 酷刑 / 死亡的细节渲染（绝对禁）

历史事实（自刎、处刑、杀戮）用**一句客观陈述**带过（"后来在乌江自刎"），**不展开过程、不具象化**。

### 模仿性的权谋教学（绝对禁）

`你将来也要学会 XX`、`这一招你也可以用`、`记住这个套路，以后开会也用得上`——讲历史 ≠ 教学生复制古人权术。

## 可以用的学术术语（但要当场解释）

初中生能理解，但第一次出现时必须配一句≤ 20 字的解释：

| 术语 | 示例解释 |
|---|---|
| 用典 | 借别人的旧故事说自己的心事 |
| 互文 | 两句话合起来才是完整意思，单读一句不够 |
| 借景抒情 | 不直说心情，让风景替你说 |
| 虚实 | "实"是眼前看到的，"虚"是脑子里想到的或回忆的 |
| 意象 | 一个反复出现的景物符号（比如"月"是思乡） |
| 对仗 | 上下两句字数相同、词性相对 |
| 炼字（诗眼） | 一句里最关键的那个字 |
| 判断句（文言） | 用"……者，……也"来表示"A 是 B" |
| 骈文 | 句子大多成对，四六相间，讲究对仗 |
| 层层递进 | 一层比一层深，后一层包含前一层 |
| 以退为进 | 表面认输，里面反打 |

第二次及以后出现时不用再解释。

## 要用但容易被误解的表达

- **"你想一下"** ——比"请思考"自然。
- **"咱们看一眼这个字"** ——比"让我们观察这个字"有温度。
- **"这一句的气口在哪"** ——讲节奏时的自然说法。
- **"这个字放在这里比别的字都准"** ——讲炼字时的具体说法。

## 不要的"讨好式"口吻

这是很容易滑过去的陷阱。要**自然松弛**，不要**刻意活泼**：

**不要**：
- "哈哈是不是很有意思？"
- "绝了！杜甫这一手太妙了！"
- "破防了！"
- "yyds！"
- 过多 emoji（标题的 icon 可以留，正文里尽量不放）

**要**：
- "读到这里，你大概能感觉到他有点撑不住了。"
- "这一句放在整首里，像一声长叹。"
- "写到这里，他停了一下——下半首就是另一个人了。"

"轻微口语化"和"讨好"的区别是：前者是"聊天的语气"，后者是"网红的语气"。

## 长度控制

**全篇总字数**：1500–2500。

分配建议（近体诗/律诗为例）：

| 模块 | 目标字数 |
|---|---|
| 1. 钩子 | 60–100 |
| 2. 作者此刻 | 120–200 |
| 3. 原文+诵读 | 100–180（不含原文本身） |
| 4. 逐层拆解 | 700–1200 |
| 5. 手法与结构 | 280–400 |
| 6. 为什么能留下来 | 200–320 |
| 7. 延伸与挑战 | 120–180 |

文言文略有不同——模块 4 更长，模块 3 更短。

**段落控制**：

- 每段不超过 4 行（渲染后）。
- 每段只有一个主意思。
- 遇到长解释要拆段，不要挤在一块。
- 适当使用空行制造呼吸感。

## 排版细节

### 标题层级

- `#` — 只给整篇主标题用一次（Obsidian 内部渲染不依赖 H1，可以省略 H1 只用 frontmatter 的`标题`字段）。
- `##` — 7 个模块 + `🔗 关联` 段。
- `###` — 模块 4 里的意义单元小标题。
- `####` — 基本不用。

### 粗体与高亮

- **粗体** 用于**第一次出现的关键概念**（比如第一次说"诗眼"时加粗）。
- `==高亮==` 用于**学生应该记住的句子**（每篇不超过 3 处）。
- 高亮和粗体**不要叠加**。

### Inline code

- 单个古字/词用 inline code，例：``最值得停下来的是 `萧萧` 这个叠字``。
- 这样做有两个好处：①视觉上突出；②避免和标点混一起难读。

### 列表

- 少用列表（列表容易把讲解打散成"知识点卡片"）。
- 只在"对比两个东西""列举 2–3 个候选"时用。
- 列表项不要超过 5 条。

### Callout 使用边界

- 每个模块开头可以用一个 callout 作为视觉锚点（见 `explanation-framework.md`）。
- **不要整个模块都放在 callout 里**——callout 适合"引文/强调"，不适合"长段讲解"。
- 一篇详解 callout 总数 ≤ 8 个（7 模块 + 原文块）。

## 标题 icon 的使用

标题图标放在 `##` 之后、文字之前：

- `## 🎣 一句话钩子`（不是 `##🎣`，中间要有空格）
- 图标统一按 `explanation-framework.md` 的映射表，不要临时发挥。

## wikilink

- 指回原文用**短名**：`[[07-登高]]`，不要写完整相对路径。
- 同作者/同朝代的导航用 **tag**：`` `#作者/杜甫` ``（用 inline code 包住 tag，避免 Obsidian 把它解析为标签触发）。

## 原文的保留规则

- 原文模块里的**原文本身**一字不改，包括异体字、通假字。
- 如果某字是通假字（比如《陋室铭》"有龙则灵"的"灵"），在模块 4 的解释里提一下它的通假关系。
- 不要把原文用 inline code 包住——原文用 `[!example]` callout。

## 写完之前的自检（硬性）

这是 Step 5 之后、**Step 5.5 之前**的风格自检。Step 5.5 的年龄对齐复核是**单独一遍 pass**，不与这份自检合并。

对照下面这些问题，至少过一遍：

1. 有没有哪一段是"为了凑满字数"写的？删掉。
2. 模块 4 有没有某一组是完全没必要精讲却在精讲的？压成一句话。
3. 模块 6 是不是又滑回"思想感情"了？重写。
4. 模块 7 的问题是不是"有标准答案"的那种？换一个。
5. 全篇有没有哪个词你自己读的时候会尴尬？（比如"破防了""yyds"）删掉。
6. 有没有连续三段都是"作者 / 诗人……"起头的？改换叙述方式。
7. 读一遍整篇，是否能**想象一个初三学生读完后愿意把这首诗读第二遍**？如果不能，重写钩子和模块 6。

**年龄适配触发项（任一命中 = 立刻重写那段，不要只改词）**：

8. 有没有出现**粗口 / 网络黑话**？（装孙子 / 打脸 / 破防 / yyds / 社死 / 拿捏 / 上桌 / 局……）
9. 有没有出现**成人化处世学术语**？（话术 / 账本 / 酒局 / 人脉 / 伏低 / 留后手 / 博弈 / 心机 / 套路……）
10. 有没有**双关 / 隐喻带成人色彩**？（特别是"让某某抬不起头"、"某某的男人 / 女人"这种结构）
11. 有没有**渲染暴力 / 酷刑 / 死亡过程**？（腐刑如何执行、刎颈过程、杀戮场景具象化）
12. 有没有**教学生模仿权谋**的句子？（"你将来也要学会 XX"、"这一招你也可以用"）
13. 有没有**黑色 / 阴郁的人生定论**收尾？（"人心不变"、"局都是一样的"、"都是一场交易"）

自检 8–13 违规 = 不能进入 Step 6。必须先修复。
