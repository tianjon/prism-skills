# 7 模块写作框架

这份文档是 `prism-guwen-tutor` 的讲解骨架。`SKILL.md` 规定结构，这里规定**每个模块怎么写**——写什么、不写什么、写多长、选什么视角。

## 12–14 岁年龄适配准则（最高优先级）

本 skill 的目标读者是初中生（12–14 岁，初三深度）。**所有写作决策的上位标准是"对这个年龄的学生是否合适"**——这一条优先于"文学表达是否精彩"、"叙事节奏是否漂亮"、"金句是否有力"等任何写作追求。

### 核心立场

学生还在**价值观形成期**。讲解的角色是**引发兴趣、打开文化视野、滋养人性理解**——不是**提前给他们灌输社会生存术**。古文当然有权谋、有算计、有暗斗——讲解可以**客观叙述这些发生了什么**，但**不要教学生模仿**。

两种写法的差别：

| 正面 ✅ | 反面 ❌ |
|---|---|
| "一个藏不住话的人守不住天下"（从项羽漏嘴一句出发讲**诚信与成熟**） | "你将来开会、谈判时也要记住，话不能随便漏"（把课文当职场培训） |
| "司马迁把屈原《离骚》的精神装进了历史写作里"（讲**文学传统**） | "这就是古代写手的 KOL 打法"（把历史庸俗化） |
| "樊哙拿命护着刘邦，是因为他认这个兄长"（讲**忠义与情谊**） | "樊哙是刘邦团队里的 MVP 打手"（成人职场化） |
| "贵族讲规矩，平民不受规矩束缚——这是两个时代的交替"（讲**历史转折**） | "要学刘邦，放下面子才能赢"（教学生"伏低" processing 哲学） |

### 禁用类别清单

| 类别 | 例词 | 为什么禁 |
|---|---|---|
| 粗俗口语 / 网络黑话 | 装孙子、打脸、吊打、社死、破防、yyds、emo、拿捏、整活、上桌、局 | 污染学生语感；家长 / 老师看到会皱眉 |
| 双关含成人色彩 | "让一个男人再也抬不起头"、"某某的男人 / 女人" | 12–14 岁仍在性心理敏感期，警惕任何此类联想 |
| 成人化处世学 | 话术、账本、酒局、人脉、伏低、装弱、留后手、给自己留退路、算计、博弈、心机 | 把学生引向功利 / 算计视角 |
| 世故黑色结论 | "人心不变，局就一直是同一张局"、"这世界就是 XX"、"都是一场交易"、"谁都一样" | 给初中生留下阴郁人生定论，违背"给学生留光"的底线 |
| 暴力 / 酷刑 / 死亡细节 | 腐刑如何执行、刎颈过程、尸体描写、杀人场景具象化 | 历史事实一句客观带过即可，不渲染 |
| 模仿性权谋教学 | "你将来也要学会 XX"、"这一招你也可以用" | 讲历史 ≠ 教学生复制古人权术 |
| 性别 / 阶层偏见表达 | "小子""妇人之仁"等贬义词作为价值判断使用 | 历史原文里出现可解释，但叙述者自己说就不合适 |

### 敏感主题的客观叙述尺度

有些主题无法回避（历史事实里就有）——这时**客观、简短、不渲染**是准则：

- **古代酷刑**（腐刑 / 宫刑 / 凌迟等）：一句带过（"古代最重的酷刑之一"），**不解释身体细节**，**不用双关**。
- **战争 / 处死**：客观陈述结果（"后来在垓下战败、自刎于乌江"），不描写过程。
- **宫廷 / 政治暗斗**：讲历史发生了什么，不把细节变成"教程"。
- **男女关系**（如《鸿门宴》"约为婚姻"、《长恨歌》等）：礼节性描述，不加情感化 / 身体化的联想。

### 正确的价值落点

古文中那些永恒的东西是：

- **友谊**（樊哙为什么豁命护着刘邦？）
- **诚信**（项羽漏嘴为什么让人替他可惜？）
- **判断力**（张良为什么总能看见两步外？）
- **责任感**（司马迁为什么活下来写完《史记》？）
- **勇气 / 面对失败**（项羽输了以后，他怎么选择？）
- **坚持**（杜甫病成那样还要登高。）

这些是初中生一辈子用得上的，而"怎么在饭局上算账本"不是。**模块 6（"为什么这篇能留下来"）的落点必须在上面这一列里**——不是在"社会生存术"。

### 写作时的段段自检动作

每写完一段，扫五个问题（对应 SKILL.md 的 Step 5.5）：

1. 有没有粗口或网络词？
2. 有没有成人处世学术语（话术 / 账本 / 酒局 / 博弈）？
3. 有没有黑色 / 阴郁的总结句？
4. 有没有双关嫌疑？
5. 有没有暴力 / 酷刑的细节渲染？

段段扫、不批量略过。这一步不是"风格优化"，是"出厂安全检查"——**违规不是扣分问题，是直接下架**。

## 总体节奏

把整篇讲解想成一条三段弧：

- **进入（模块 1–2）**——把学生拉到诗/文的门口。这里还不要讲"知识"，只要让学生愿意往里走。
- **深入（模块 3–5）**——在作品内部完成"看清楚→理解为什么这么写"的过渡。这三节是讲解的主体。
- **跳出（模块 6–7）**——把作品和学生的生活/经验连接起来，然后留一个开放的问题送出去。

三段弧缺一不可。多数"无聊的讲解"是卡在中间那一段打转。

| 3. 原文+诵读 | ●●● | ●●● | ●● | ●●● |

**口诀**：

- 文言散文——重 **叙事与论证逻辑 / 思想延伸**（4 / 7）
- 骈文——重 **句式与对仗 / 典故使用**（3 / 5）

## 模块 1 · 一句话钩子 Hook

**Callout 建议**：`> [!question] 读之前想一下……`

**目的**：让学生在看到原文前就被吸引。

**写法可选**（挑**一种**，不要叠加）：

1. **反直觉问题**：例"凌晨三点有人砸你家门，开门是'警察'，可是爷爷立刻翻墙跑了——这是杜甫亲眼看到的一晚。"
2. **现代类比**：例"这首词放到今天，相当于一条朋友圈只发了九个字，却让一千年里所有人都转发了。"
3. **戏剧性场景**：例"他站在山上，风很大，吹得帽子差点飞了。他想起半年前还在洛阳的花园里喝酒——那是五十六年人生里最后一次。"

**不要写成**：
- "这首诗是唐代著名诗人 XX 的代表作之一"——套话开头，扣分。
- "同学们，今天咱们来学一首新诗"——教师腔。
- 超过 80 字的长段落——钩子要快。

**长度**：1–3 句，≤ 100 字。

## 模块 2 · 作者此刻 Author in the Moment

**Callout 建议**：`> [!info] 📍 作者此刻（公元 XXX 年）`

**目的**：把作者还原成**写这篇作品那天**的一个具体的人。

**必须回答的三个问题**：

1. **他/她多大？** 不要"少年时代""晚年"这种模糊词，给出具体的年龄数。
2. **人在哪里？** 地名 + 此刻的具体环境（流放途中 / 贬官之后 / 刚登完高 / 屋漏偏逢连夜雨）。
3. **心里在想什么？** 不是"忧国忧民"这种标签，而是**此刻脑子里在过的那件具体事**。

**写法示例**（杜甫写《登高》时）：

> 这一年杜甫 56 岁，住在夔州（今天的重庆奉节）一个破旧的土屋里。他的身体已经很差——糖尿病、肺病、风湿、耳朵半聋；半年前他戒了酒，因为再喝下去命都保不住。这天是重阳节，按老规矩要登高望远、喝菊花酒，可他连酒都不能碰。他爬上江边的一处高台，风吹在脸上，他开始写这首诗。

**避免**：
- 生平流水账（"字子美，号少陵野老，河南巩县人，自幼聪颖……"）——这是百科，不是讲解。
- 脱离"此刻"跳到"一生"的评价——留给模块 6。
- 用"代表作""经典之作"这类外部评价——你不是广告文案。

**长度**：100–200 字。

## 模块 3 · 原文 + 诵读提示 Recite

**Callout 建议**：`> [!example] 原文`（完整原文用这个 callout 包住）

**内容构成**：

1. **完整原文**（一字不改，标点按现行版本）。
2. **节奏标注**（诗用 `/`，如 `无边/落木/萧萧下`；文言长句用 `、` 标断句点）。**可选**，但对初中学生很有用，因为他们常常不会断。
3. **韵脚标注**（仅诗 / 词）——在每一句末尾韵脚字后加 ⟨韵⟩ 或括注（"哀 / 回 / 来 / 台 / 杯"压 -ai/-ui 通押）。
4. **一句诵读建议**——告诉学生"这首应该怎么读"。例：
   - 诗：`这四句要一句比一句低，最后"凄凄"两字几乎是气声。`
   - 文：`前半声调要稳，到"南阳诸葛庐"这句可以稍扬一点，像在亮底牌。`

**不要**：
- 列半版韵书的知识（"平水韵十灰""古入声派入去声"……）——学生看不懂。
- 在这里就开始翻译——翻译在模块 4。

**长度**：100–200 字（诵读建议部分；原文本身不计）。

## 模块 4 · 逐层拆解 Close Reading

**Callout 建议**：不用整段 callout 包；每组意义单元前用 `### <两句节录>` 作小标题，下面直接写。

**这是主体**（占全篇字数的 40–50%）。

**分组原则**：

- **诗**：按联 / 句分组，通常每 2 句一组（律诗 4 组，绝句 2 组，词按上下片分）。
- **文言**：按**意群**分组（一句话在说什么完整意思），通常 30–80 字一组。

**每一组只做三件事**：

1. **字面在说什么**——简明翻译。**不要逐字**，也不要堆形容词。一两句话说清楚即可。
2. **哪个字/词是关键**——挑这一组里最值得停下来的那个字、词、或一个小转折，解释**为什么它是关键**。
3. **这一组在整篇中的作用**——铺垫？转折？收束？类比？举例？

**精讲点控制**（核心）：

- 全篇只精讲 **2–3 个点**。其他组一笔带过即可。
- 精讲点的选择标准：①这个字/词/句被后世引用或化用最多；②去掉它整首诗就塌了；③它最能代表本篇的特色。
- 精讲段单独多用 3–5 句，展开"为什么"。非精讲段一组 2–3 句说完。

**示例**（《登高》颔联）：

> ### 无边落木萧萧下，不尽长江滚滚来
>
> 字面很简单：漫山遍野的落叶被风吹着飘下来，长江的水望不到头，滚滚东流。
>
> 真正的精讲点在 `萧萧` 和 `滚滚` 这两个叠字。一静一动——落叶是时间在"沙沙"地倒下去，江水是生命在"哗哗"地奔过去。你念出来的时候，两个音节的差别就能听到："萧萧"是轻的、涩的；"滚滚"是重的、推的。
>
> 这两句在整首诗里是什么作用？——把视角**从身边推到宇宙**。前一联写小景（风、鸟、沙洲），这一联一下子推到秋天和长江这种巨大的尺度。诗人还没开始讲"我"，但"我"已经被这个大景压住了。

**绝对不要**：
- 字字翻译（"风：风。急：又大又猛。天：天空……"）——这是字典，不是讲解。
- 每一组都精讲——学生会睡着。
- 用"运用了 XX 手法"起头——留给模块 5，且用法要改。

**长度**：600–1200 字。

## 模块 5 · 手法与结构 How it Works

**Callout 建议**：`> [!tip] 🎨 作者是怎么做到的`

**目的**：从"写了什么"升到"怎么写的"。初中学生刚好进入能处理抽象的阶段，所以这一节是让他们"长见识"的关键。

**原则**：

- **只挑 1–2 个本篇最突出的手法**，讲透。
- **不要列清单**（"本诗运用了对仗、借景抒情、用典、虚实结合……"）。这种是高中应试总结，不是讲解。
- 第一次出现的术语（"互文""用典""意象""虚实""判断句""被动句"等）要**在句子里塞一句 20 字以内的解释**。例："用典——就是借别人的旧故事说自己的心事。"

**诗/词常挑**：对仗（尤其当句对/通体对）、意象叠加、虚实转换、时空对置、叠字、炼字（"诗眼"）。

**文言常挑**：叙述视角、论证结构（起承转合 / 总分总 / 层层递进）、句式特色（判断句"……者，……也"；骈散结合；短句的节奏）、用典。

**示例**（《陋室铭》）：

> 本篇最值得停下来讲的，是它的 `反证法结构`。
>
> 标题叫"陋室铭"，字面意思是"一间破屋子的铭文"。按常理，作者应该为自己辩解："这屋子虽然破，可我心里……"。但刘禹锡偏偏相反——他直接上来就说"山不在高，有仙则名"。这是在告诉你：判断一间屋好坏，根本不在"屋"本身，在住里面的那个人。
>
> 接下来七八句，他把屋里的生活一样一样摊开——谈笑的是大儒、弹的是素琴、读的是金经——每一样都在暗暗说"这就是我"。到最后一句"何陋之有"反问一出，整篇反过来了：这屋一点都不陋，反而很牛。
>
> 这叫**以退为进**。表面认输，内里傲到骨子里。你写自己家被人嫌弃的时候也可以学一下——不用辩解，直接把屋里那盏灯的故事讲给别人听。

**长度**：250–400 字。

## 模块 6 · 为什么这篇能留下来 Why it Endures

**Callout 建议**：`> [!quote] 🌍 为什么一千年后还有人在读`

**目的**：把作品和学生的**普遍人类经验**连起来。这是整篇最难写、也最重要的一节——是整份讲解的"价值锚"。

**不要写成**：

- "这首诗表达了诗人 XX 的思想感情"（禁用。）
- "本诗的中心思想是 XX"（禁用。）
- "告诉我们要 XX"（道德课。禁用。）

**要写成**：

- **找到本篇击中的那个普遍情境**——不是"思乡"这么抽象，而是"你在外地读书，半夜突然想回家但下周才放假"这种**具体的当代切片**。
- **给学生一个情境预判**："等将来你也……的时候，你会突然想起这七个字"。让学生对这首诗"**有期待**"，将来再遇到类似时刻会自动想起来。

**示例**（《登高》）：

> 《登高》真正击中的不是"秋天的悲伤"这种大词。它击中的是很具体的一件事——
>
> 一个人意识到"我老了，病了，没人陪，还回不了家"的那一瞬间。
>
> 这种时刻每个人都会遇到，只是有人 30 岁，有人 60 岁。你现在可能还没遇到，但总有一天——你在外地过节、刚生完一场病、站在高楼上看秋风吹过城市，或者只是某个加班到深夜的凌晨——你会突然想起"万里悲秋常作客"这七个字。那一刻，杜甫就在你身边。
>
> 好的古诗不是让你"懂"它，是等你有一天**需要它**。

**长度**：200–350 字。

## 模块 7 · 延伸与挑战 Go Further

**Callout 建议**：`> [!question]- 🪄 想一想 / 读一读（点击展开）`

**目的**：把讲解从"结束"变成"起点"。

**内容**：1–2 个**开放性问题**或**对比阅读**，**不给标准答案**。

**可选题型**：

1. **对比阅读**：挑一首同主题/同作者/同题材的相邻作品，让学生自己比较。
   - 例："李白也写过登高（《登金陵凤凰台》），和杜甫这首比，你更喜欢哪一首？为什么？"
2. **视角改写**：换人称/视角改写会损失/得到什么？
   - 例："如果把《石壕吏》的视角从第三人称旁观改成老妇人自述，会损失什么？会得到什么？"
3. **现代处境投射**：用作品的句子描写一个当代场景。
   - 例："用《陋室铭》的句式写一段你自己书桌/卧室的'铭'，给什么样的东西配什么样的理由？"
4. **一个反问**：针对作品里最有张力的地方问一个可以有多种答案的问题。
   - 例："《登高》最后两句说他戒了酒。如果这天他能喝一杯，他会写出一样的诗吗？"

**注意**：

- 不要写"请讨论 XX 的思想感情"这种议论文式问题。
- 不要写"根据课文回答……"这种语文试卷式问题。
- 每个问题要**真的没有标准答案**。

**长度**：100–200 字（含问题本身）。

## 模块 8（可选）· 🍵 大师漫谈

**开启条件**：见 `SKILL.md` 的"可选第 8 模块"章节——必须满足作品有真实可查的名家评点、且文化分量够。不满足 → 不开；**"开错了"比"不开"更伤害**。

**Callout 建议**：模块开头**不**用整段 callout；模块内部的**真实引文**用 `> [!quote]` 做节拍点。

**目的**：把学生从"字词文本"带到"文化土壤"里。通过**真实名家的真实话语**让学生听见两千年来读过这篇的前人是怎么评价它的——这是"文化熏陶"最有效的方式。

### 硬约束

**每一条都要满足，差一条即不合规**：

#### 1. 全程第三人称

叙述框架是："鲁迅在《汉文学史纲要》里讲过 XX"、"苏辙在《上枢密韩太尉书》里说 XX"、"赵翼在《廿二史札记》卷二里提出 XX"——**不是**"默存先生说——我在《管锥编》里……"。

**第一人称扮演大师的做法明确禁止**，三条原因：

- 大多数情况下会涉及编造（除非有录音 / 讲稿 / 对话实录，否则不知道大师会用什么语气讲这段）。
- 学生会误以为这是大师原话，把"扮演的话"当"真文献"记在心里。
- 即便不编造，也在灌输"我在替大师代言"的虚假权威。

#### 2. 每条引用可核查

优先级从高到低：

- **顶级**：大师的**真实原文直引**。例：鲁迅"史家之绝唱，无韵之离骚"（《汉文学史纲要》第十篇）；苏辙"行天下，周览四海名山大川，与燕赵间豪俊交游，故其文疏荡，颇有奇气"（《上枢密韩太尉书》）。
- **次级**：**学界公认的条目或论断**。例：赵翼《廿二史札记》卷二"汉初布衣将相之局"这个条目名；《史记》《汉书》对同一人物的不同体例处理（《项羽本纪》vs.《汉书·陈胜项籍传》）。
- **禁止**：根据训练语料"生成"的、无可靠出处的"大师名言"。任何"据说鲁迅说过"、"王国维评价"但记不清具体出处的 → **一律不写**。

**不确定就不写**——宁可模块内容少，也不编。

#### 3. 连贯主线叙事（不拆子标题）

**禁止**把大师漫谈切成 6 个 `### 小标题` 的拼贴。整段像一条河顺下来，段与段之间用过渡词连接，读者跟着一条线走到底。推荐的叙事骨架：

```
起笔：一位大师的定评（如鲁迅的十三字）
↓ "这种 XX 是怎么来的？"
过渡到创作过程（如苏辙谈司马迁走天下）
↓ "正因为是这样写来的"
过渡到笔法的小例证（原文里一句话作锚）
↓ "而他的判断还不只在笔法里"
过渡到体例 / 格式的判断（本纪 vs. 列传）
↓ "把镜头再拉开一层"
过渡到历史 / 文化背景（赵翼 / 田余庆等真实史学观点）
↓ "留到今天的还有一样极具体的东西"
过渡到语言 / 成语 / 文学传承
↓
收束一句凝练的"两千年体量"的落点
```

段与段的衔接词决定这根主线是否立得住——"这种……是怎么来的？""正因为是……""而……还不只在……""把镜头再拉开一层""最后再退远一步看"——这些是必要的接榫。

#### 4. 引文 callout 做节拍器

真实引文必须用 `> [!quote]` 单独拎出，做视觉节拍点：

```markdown
> [!quote] 鲁迅 · 《汉文学史纲要》第十篇
> 史家之绝唱，无韵之离骚。
```

```markdown
> [!quote] 苏辙 · 《上枢密韩太尉书》
> 行天下，周览四海名山大川，与燕赵间豪俊交游，故其文疏荡，颇有奇气。
```

```markdown
> [!quote] 赵翼 · 《廿二史札记》卷二
> 汉初布衣将相之局。
```

引文 callout 之间是正文的解读段。整节读起来是"骨肉分明"的——大师一句 → 你（讲解者）一段 → 大师一句 → 你一段。这是**印刷级排版**的核心做法——避免一整面纯文字墙。

#### 5. 与模块 5 严格分工

- **模块 5（手法与结构）** → 讲**笔法技术**（以动作塑造人物、座次政治学、骈散结合、炼字、虚实等）。
- **模块 8（大师漫谈）** → 讲**文学史 / 历史背景 / 文化传承**（鲁迅定评、苏辙谈创作、赵翼谈时代、成语沉淀、文学血脉）。

**互不重叠**。如果发现模块 8 里写到了"以动作塑造人物"—— 立刻删，这是模块 5 的领地。

#### 6. 人称一律

叙述者是"客观讲解者"，**不用"我"**。需要"看向读者"时用"你"（"读《鸿门宴》要把它放进心里"——可以；"我认为你应该把它放进心里"——不行）。

### 写法反面（绝对不出现）

- "默存先生说——"、"鲁迅先生曾经告诉我们……"——**伪托第一人称**。
- "大师们一致认为……"——**无出处的群体引用**。
- "XX 在 YY 里深刻地指出……"——**空洞赞颂**（给具体引文，不给空话）。
- "鲁迅说过这篇是中国小说的开山之作"——**借大师之口塞编造的观点**。

### 长度

**700–900 字**。

- 不足 700 → 说明真实可引的材料不够 → 应**关闭本模块**。
- 超过 900 → 说明偏离主线太远 → 压缩（优先压每段的解读部分，保留引文本身）。

### 年龄适配（与本模块特别相关）

大师漫谈很容易滑向"成人化"——因为引进大师、学术术语、历史判断时，叙述语气容易变重。**必须在写完后走一遍 Step 5.5 年龄对齐复核**：

- 引入的大师判断要**指向人性 / 文化 / 历史规律**，不指向"社会生存术"。
- 赵翼"布衣将相之局"这种历史判断可以引，但**落点在"这是中国历史的一次换底"**，不是"平民出身的人更容易成功"。
- 田余庆 / 钱穆这类史学判断在讲的是**历史的结构**，不是**怎么往上爬**。
- 每个真实金句引进来之后，跟的那段解读要**面向 12–14 岁**——语言浅白、不掉书袋、不用"权力学""博弈论"这类术语。

### 收束

最后用一句**凝练的、单独成行的**句子作句号。例：

- 《鸿门宴》→「**一张饭桌，两千年。**」
- 《岳阳楼记》→「**一篇记，一代士。**」

"两千年体量"的落点是合适的——要**开阔、要有光**，不要世故、不要阴郁。

## 初三档写作参数

本 skill 固定按 **初三（九年级）** 难度写作。下面的参数对**所有作品**都适用——哪怕原文出自小学课本或高中必修，也按同一把尺子。

### 为什么固定初三

- **稳定的深度预期**：学生（或家长）打开任何一篇详解都知道能读到什么深度，不用揣测"这篇是按几年级写的"。
- **避免错误派生**：skill 不必根据 frontmatter 的 `年级` 字段去切换档位——一切错误派生都被消除。
- **初三是一个平衡点**：它刚好能撑住审美（够深）又还没滑进高中的应试八股（够活）。往下可选的是"应试"（`focus: 应试`），往上可选的是"思辨"（`focus: 思辨`），覆盖绝大多数需求。

### 用词深度

术语**自然使用**，第一次出现时给一句 ≤ 20 字的解释（见 `style-guide.md` 的术语解释表）；第二次起直接用不再解释。

反面：
- 不要**每次**都解释（把学生当小学生）。
- 不要**完全不解释**（把学生当文学系本科生）。
- 不要用高中文论才出现的抽象概念（"审美主体""接受美学""意识流"等）。

可以自然使用的术语示例：`对仗 / 诗眼 / 炼字 / 意象 / 虚实 / 借景抒情 / 用典 / 互文 / 判断句 / 被动句 / 词类活用 / 通假字 / 骈文 / 层层递进 / 以退为进`。

### 注释密度（模块 4 里的字词讲解）

| 类别 | 处理强度 |
|---|---|
| 生僻字注音 | 注 |
| 非常用字注音 | 不注（高频字假设学生认识） |
| 字义 | 讲透关键字（精讲点涉及的那 2–3 个） |
| 古今异义 | 碰到就讲透 |
| 词类活用 | 讲 1–2 个本篇最关键的 |
| 通假字 | 讲（作为"有意思的冷知识"出现，不作考点罗列） |

**原则**：字词讲解**不要单独开一节**，而是自然穿插在 Close Reading 里——碰到哪个关键字就顺手讲一下，不必求全。求全就会滑向"字词积累"式的机械注释。

### 模块 5（手法与结构）展开深度

- 讲 **1–2 个**本篇最突出的手法。
- 每个都要讲到 **"在这里起了什么作用 / 为什么这么写比那么写好"**，不能只点名字。
- 总字数 **280–400 字**。

### 模块 7（延伸与挑战）题型倾向

优先选：

- **对比阅读**：挑一首同主题/同作者/同题材的相邻作品，让学生自己比较。
- **一个真正开放的反问**：针对作品里最有张力的地方问一个可以有多种答案的问题（例如"如果他这天能喝酒，还会写出一样的诗吗？"）。

可选但不要作为唯一题型：

- 现代处境投射（你在什么时刻会想起这首诗）。
- 视角改写（换人称/叙事视角会损失什么）。

### 总字数

**2000–2500 字**（不含原文引用本身、不含 frontmatter）。

分配建议（近体诗/律诗）：

| 模块 | 目标字数 |
|---|---|
| 1. 钩子 | 60–100 |
| 2. 作者此刻 | 150–220 |
| 3. 原文+诵读 | 120–180（不含原文本身） |
| 4. 逐层拆解 | 800–1200 |
| 5. 手法与结构 | 300–400 |
| 6. 为什么能留下来 | 250–350 |
| 7. 延伸与挑战 | 120–200 |

文言散文微调：模块 4 更长（900–1300），模块 3 更短（80–140）。

### 侧重（`focus` 参数）对应调整

`focus` 参数**不改难度档**，只改 7 模块内部的重心分配：

- `审美`（默认偏重）：模块 6 扩到 300–400 字；模块 4 的精讲点偏向"声音 / 意象 / 感觉"；模块 5 偏美感向手法（炼字 / 意象 / 虚实）；字词讲得更松。
- `应试`：模块 4 多放一个精讲点在中考常考点；模块 5 的手法名目写清楚（仍避免列清单）；字词讲得更密（通假 / 活用 / 常考虚词必点）；可在模块 4 某处加一个 `[!note]- 中考常考` 折叠 callout。
- `思辨`：模块 5 和 6 的连接更强（手法 → 为什么这么写 → 这么写意味着什么）；模块 7 偏向价值判断 / 视角切换；允许模块 6 引入另一位作家/另一首诗做横向对比。

默认 `审美 60% + 应试 40%`——模块 6 拿满审美字数，模块 4 保留应试字词点位，模块 7 放一道思辨反问。这个组合覆盖绝大多数日常需求。
